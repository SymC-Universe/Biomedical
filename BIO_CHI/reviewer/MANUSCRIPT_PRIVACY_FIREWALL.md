# Working manuscript privacy firewall

**Rule:** active working manuscript text for Bio Chi is private.

## Public GitHub may contain

- scientific contracts and preregistrations;
- code;
- tests;
- environment files;
- source manifests and hashes;
- compact results;
- figure/table generators and provenance;
- claim/evidence maps;
- null/failure/refusal ledgers;
- reviewer responses after authorization;
- release/submission manuscript snapshots after explicit authorization.

## Public GitHub may not contain during active drafting

- current working manuscript source;
- unreleased narrative drafts;
- private editorial strategy;
- unpublished response-letter drafts unless explicitly released.

## Private location

`/Atlas - Chi Bio/Private Working Manuscripts`

A public status stub may identify that a private working manuscript exists, but must not reproduce its text.
