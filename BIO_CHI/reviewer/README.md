# Bio Chi reviewer entry point

This directory is the reviewer-facing navigation layer for the Bio Chi investigation.

## What this repository is designed to let a reviewer do

A reviewer should be able to determine:
- what biological event was asked;
- what was frozen before outcomes were opened;
- which source files and carriers were used;
- how source identities were verified;
- what code produced each result;
- which comparators and nulls were used;
- what failed, refused classification, or remained source-limited;
- which claims are supported and which are not;
- how each reported result can be rerun;
- which exact commit/workflow/artifact generated a reported value.

- No universal biological scalar value, chi=1 boundary, master scalar, universal Bio Chi law, or causal Stability Inheritance law is established.

## Manuscript privacy

Working manuscript text remains private during active investigation. The public repository carries the reproducibility and evidence spine. A submission/release snapshot is exported only when authorized.

## Reviewer reproducibility policy

Every promoted result receives a provenance record containing source identity/hash where available, code/config commit, environment identity, workflow run and artifact identity, endpoint/comparator definitions, uncertainty/multiplicity rules, disposition, and claim ceiling.

No favorable result may erase an unfavorable result from the same frozen program.
