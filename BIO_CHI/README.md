## Reproducibility rule

- source identifiers and hashes;
- acquisition instructions;
- preregistrations and amendments;
- executable code and pinned environments;
- tests and known-bad cases;
- compact result tables;
- figure/table generation code;
- null/failure/refusal ledgers;
- claim-to-evidence maps;
