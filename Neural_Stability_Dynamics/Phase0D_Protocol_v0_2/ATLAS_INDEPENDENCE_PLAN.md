# Neurostability Atlas Independence Plan

Status: Atlas not yet qualified.

The Atlas must remain read-only with respect to Structural Engine rules during confirmatory use.

Before real-data validation, each decisive atlas reference family will record:

- raw evidence source;
- whether the source data were used in engine development/calibration;
- whether labels/outcomes entered estimator construction;
- whether thresholds were tuned against the atlas;
- whether fitted parameters/simulations are shared;
- whether extraction was blind to engine results where feasible;
- independence grade: INDEPENDENT, PARTIALLY_INDEPENDENT, or NON_INDEPENDENT_FOR_ENGINE_VALIDATION.

TDBRAIN data used to assess real-data adequacy cannot simultaneously count as independent atlas validation of that same engine behavior without an explicit dependence grade.
