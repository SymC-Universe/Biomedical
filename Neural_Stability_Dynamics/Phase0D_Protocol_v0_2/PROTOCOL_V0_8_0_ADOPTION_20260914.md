# General Protocol v0.8.0 Adoption Note

Date: 2026-09-14
Status: **ACTIVE GOVERNANCE POINTER FOR CURRENT NSD WORK**

## Authoritative baseline

The current authoritative General Cross-Project Research Protocol is **v0.8.0, dated 14 September 2026, status `Definitive Active Baseline`**.

The NSD branch had previously adopted v0.7.7. Adoption of v0.8.0 does not retroactively rescore, reinterpret, promote, demote, or rerun any historical NSD result, gate, failure, survival status, hold, evidence tier, or frozen scientific commitment.

The v0.8.0 file states that it supersedes v0.7.8. The directly available prior NSD program baseline for this migration was v0.7.7; no v0.7.8 artifact was available in the NSD branch or the protocol file set used for this migration audit. This lineage gap is recorded rather than silently inferred.

## Material v0.8.0 consequence for NSD

v0.8.0 consolidates the General Protocol around transferable program-wide safeguards and explicitly moves project-specific equations, dataset conventions, Atlas targets, implementation details, and domain-specific machinery into project protocols unless they are needed to execute a general rule safely.

For NSD this means the local scientific contract and project records now carry greater source-of-record responsibility. Existing NSD-specific restrictions remain active unless explicitly versioned. In particular, the project continues to preserve:

- scalar, vector/modal, and conglomerate/system representations as starting components rather than a complete decomposition of chi;
- prohibition on a whole-system scalar unless separately derived and validated;
- pre-Atlas coordinate independence and no label/outcome leakage into structural selection;
- claim-specific gates, open-channel structure, refusal, partial admission, and unresolved states;
- Function Map and Limit Map as coequal P0 targets;
- separation of local dynamical identity from embedded realized behavior;
- hierarchical closure and recovery/resilience as separately auditable objects;
- the complete MFR-14 floor before P1;
- and the current P1 closure.

## Scientific core preserved

The v0.8.0 consolidation preserves the program safeguards material to the present NSD stage: MFR-14, native-model-first derivation, epistemic classification, P0-D/P0-Q/P1/P2 separation, promotion debt, independence, refusal, Function/Limit mapping, foundational dependency, run economy, monitoring, reproducibility, and relational/hierarchical stability.

Therefore no current NSD calculation requires restart solely because of the protocol migration.

## Monitoring determination

No persistent external compute dependency remains active for those runs. Monitoring therefore moves from active-run observation to post-run artifact and closure auditing. A persistent watchdog becomes expected only if a later dependency class makes it proportionate and useful.
