# NSD Prediction and Structural-Lineage Grammar Draft

Date: 2026-09-11
Status: P0-D CONCEPT / FORMALIZATION DRAFT. NOT FROZEN. NOT P0-Q. NOT P1.
Protocol: General Cross-Project Research Protocol v0.7.1 FINAL + authoritative v0.7.1A Addendum

## Why this exists

The System Model v1.0 is locked, but a future predictive Tool still needs an explicit answer to a harder question: **what exactly would count as an NSD prediction?**

The safest predictive target is not diagnosis or a desired scalar zone. It is a prospective statement about the continuation, reorganization, loss, emergence or non-identifiability of already defined System-Model objects under a new window, perturbation, condition or system.

This draft defines a grammar for such statements without selecting thresholds or claiming that any statement is already validated.

## 1. Structural lineage as a derived conglomerate representation

For each window or condition t, let the Engine return a set of supported claim objects:

M_t = {individual modes, crowded subspaces, observable-order state, participation structure, open-channel state}.

A structural-lineage graph links resolvable objects between t and t+1. An edge may carry multiple **non-aggregated** attributes:

- pole displacement or interval overlap;
- carrier similarity when individual identity is resolvable;
- principal-angle/subspace similarity when individual identity is not resolvable;
- channel-participation redistribution;
- observable-order change;
- adequacy state in each window;
- uncertainty/assignment ambiguity;
- method agreement/disagreement.

No single weighted lineage score is assumed. The graph is a representation of evidence, not an adjudication rule.

## 2. Candidate lineage events

These are descriptive event names, not frozen thresholds.

### PERSIST
A supported object remains resolvable in the next condition/window with compatible native spectral and carrier/subspace evidence.

### DRIFT
The same resolvable object remains identifiable while one or more native coordinates move continuously.

### MERGE_OR_CROWD
Previously separable individual carriers cease to support stable one-to-one identity while a joint subspace remains supported.

### SPLIT_OR_RESOLVE
A previously joint/crowded object becomes resolvable into more specific supported objects.

### LOSS_FROM_OBSERVABLE_STRUCTURE
An object no longer remains identifiable in the measured observable subspace. This does not imply destruction of the latent mechanism.

### EMERGENCE_IN_OBSERVABLE_STRUCTURE
A newly supported observable object appears. This does not automatically imply a newly created biological mechanism.

### REORGANIZE
The supported system structure changes in relational geometry, participation, order or subspace organization without a simpler one-object birth/death interpretation.

### REFUSE_LINEAGE
The requested cross-window identity cannot be supported because adequacy, uncertainty, assignment ambiguity, crowding or incompatible representations prevent a defensible linkage.

## 3. Candidate prediction classes

A future preregistered prediction should specify the claim object, perturbation, horizon, permitted evidence and falsifier before decisive evidence is inspected.

### PRED-1: Persistence prediction

Form:
"Object/subspace X should remain identifiable after perturbation P over horizon H."

Falsifier class:
The object is not recoverable at the claimed level under adequate data, or only a weaker representation survives.

### PRED-2: Reorganization prediction

Form:
"Perturbation P should reorganize the observable modal/system structure rather than merely translating all native coordinates together."

Falsifier class:
The structure remains statistically/epistemically compatible with persistence at the preregistered resolution.

### PRED-3: Resolution-loss prediction

Form:
"Under increased crowding or reduced observability, individual identity should become unresolved before the joint supported subspace disappears."

This is strongly motivated by P0-D2/P0-D3 but is not prospectively qualified by those same records.

### PRED-4: Observable-order transition prediction

Form:
"Condition P should change the effective observable structural order/rank while leaving specified dominant structure recoverable."

Falsifier class:
No supported order change occurs, or the dominant structure is not retained as claimed.

### PRED-5: Adequacy-break prediction

Form:
"After change P, the current local linear/state-space description should cease to be adequate at claim level L even if a numerically stable fit can still be produced."

This explicitly predicts **model failure** rather than forcing a coordinate.

### PRED-6: Refusal prediction

Form:
"Under condition P, the Engine should return REFUSE/UNRESOLVED/INDETERMINATE for claim object X rather than fabricate a stable scalar/mode identity."

A correct refusal is a successful prediction if the refusal criterion was frozen independently and the decisive evidence was untouched.

### PRED-7: Recovery/return trajectory prediction

Form:
"After a transient perturbation, specified structural objects should return toward a prior reference organization over horizon H, while other objects may remain reorganized."

This requires genuine longitudinal/transition evidence and should not be inferred from cross-sectional cohorts.

### PRED-8: Cross-system transfer prediction

Form:
"A claim rule qualified on system family A should preserve its stated epistemic behavior on independent system family B within a bounded declared scope."

Failure to transfer narrows scope rather than automatically invalidating all within-system results.

## 4. What is intentionally NOT a default NSD prediction

The following are downstream questions and must not be smuggled into the structural prediction layer:

- diagnosis;
- clinical outcome;
- treatment response;
- phenotype classification;
- a desired chi value or universal stability zone;
- anatomical mechanism from carrier shape alone;
- latent disappearance from observable disappearance;
- universality across neural systems.

These may become later application questions only after independent structural validation and explicit admission rules.

## 5. Potentially high-value prospective experiments

These are brainstorming candidates only.

1. **Within-subject rest -> task -> rest lineage:** predict which subspaces persist, which reorganize under motor task, and whether post-task rest returns toward pre-task organization.
2. **Wake -> sleep-stage transition lineage:** predict resolution/order/subspace changes across independently staged transitions without using stage label in structural fitting.
3. **Pre-event -> event -> recovery natural-limit lineage:** in seizure data, freeze structural rules without event labels, then ask whether the Engine prospectively detects reorganization or correctly refuses around independently annotated events.
4. **Channel-ablation stress test:** predict degradation from individual modes to subspaces to unresolved state as observability is experimentally reduced.
5. **Window-length stress test:** predict which claim levels survive shorter records and where uncertainty rather than point instability becomes the limiting object.
6. **Cross-method lineage agreement:** compare whether independently qualified estimators agree on persistence/reorganization at the claim-object level even when individual numerical pole estimates differ.

## 6. Brainstorming hypothesis generated from current P0-D evidence

A potentially important architecture-level hypothesis is:

> **Neural stability may be more faithfully represented by preservation/reorganization of dynamical lineage across perturbations than by proximity to any single scalar coordinate.**

This is not a result. It is a hypothesis generated after observing P0-D2/P0-D3/P0-D4 and therefore requires independent prospective tests.

If supported, scalar coordinates would remain useful compressed descriptors, modal objects would describe resolved structure, and the conglomerate lineage would describe how the organization survives or changes. This preserves the standing scalar + modal + system framing rather than replacing one layer with another.

## 7. Freeze boundary

Nothing in this document freezes:

- similarity thresholds;
- pole-distance thresholds;
- uncertainty overlap criteria;
- subspace-angle thresholds;
- event definitions;
- prediction horizons;
- scoring;
- clinical interpretation;
- P1 challenge design.

Those require separate P0-Q evidence and explicit review before prospective use.
