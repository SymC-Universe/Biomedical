# NSD Protocol Baseline

Authoritative baseline: **General Cross-Project Research Protocol v0.8.0**, dated 14 September 2026, status `Definitive Active Baseline`.

This supersedes the v0.7.7 pointer previously used by this branch. Historical branch names, runs, artifacts, freezes, failures, survival statuses, and evidence tiers are preserved and are not retroactively rescored by this pointer update.

The v0.8.0 source states that it supersedes v0.7.8. The directly available prior NSD baseline for this migration was v0.7.7; the absence of a v0.7.8 artifact from the audited NSD branch/file set is preserved as a lineage-documentation gap rather than filled by inference.

This project inherits the complete program protocol. This file is only an implementation pointer and does not restate or weaken the source protocol. Project-specific measurement, inference, Atlas, and implementation safeguards are maintained locally under the v0.8.0 internal-use transfer principle.

Current process tier: **P0**, explicitly split into:

- **P0-D - discovery and mechanism/functional mapping**;
- **P0-Q - qualification and controlled iteration**.

Canonical maturity path:

`P0-D discovery -> P0-Q qualification -> P1 frozen confirmation -> P2 release/tool qualification`

Canonical architecture:

`NSD System Model -> implemented by NSD Structural Engine`

`NSD System Model + Independent Neurostability Atlas -> NSD Tool`

`Validated NSD System Model + Independent Neurostability Atlas + Prospective Validation -> Predictive NSD Tool`

Current ceiling: **System Model and Structural Engine P0 development/qualification only. P1 is closed.**

Function Map and Limit Map remain coequal targets. Scalar, vector/modal, and conglomerate representations remain starting components for progressively reconstructing chi architecture, not a complete decomposition or arithmetic aggregation. Local dynamical identity and embedded realized behavior remain separate audited objects. Whole-system scalars and hierarchical closure must be earned rather than assumed.

Active program controls include:

- foundational-dependency robustness when the activation conditions are met;
- run economy, preflight, bounded retry, and resumable checkpoints for substantial computation;
- active-run monitoring and monitor-coverage audit proportional to dependency class;
- new-session loading of current GP and source-of-record repository state before inheriting active work;
- experimental-opportunity/literature-collision and attribution controls when triggered;
- reader-first communication;
- bounded scope language and the program-level falsification architecture.

Current NSD-specific measurement and inference safeguards are maintained in `NSD_MEASUREMENT_AND_INFERENCE_SAFEGUARDS.md` together with the existing scientific contract and source-of-record project records.
