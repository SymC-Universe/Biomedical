# Three-Layer Rationale: Phase 0D

The working decomposition is:

**scalar state <-> carrier/modal structure <-> whole-system organization**

These are complementary observables, not interchangeable summaries.

## Layer A: scalar-spectrum state

For each locally selected segment, complex poles describe decay and oscillation. Split-record pole movement is a scalar-state change. Cross-order stability is checked inside the same local segment. No whole-system scalar is constructed.

## Layer B: carrier/modal structure

Observable mode shapes answer what carries a mode in measurement space. Carrier comparison must remain meaningful even when pole values change, so matching is driven by MAC and invariant-subspace similarity. When modes crowd, individual eigenvectors are suppressed and the joint subspace is the licensed object.

## Layer C: whole-system organization

The system representation is a tuple:

`(local observable order, observable subspace/projector, normalized channel participation, resolved-cluster spectral geometry)`

The tuple is not averaged into one score.

Relational pole geometry is only licensed between resolved clusters. Within a crowded cluster, individual splitting is not stable enough to support a relational claim. When fewer than two resolved clusters exist, the geometry component is `UNRESOLVED`; the carrier/projector and participation components can still be tested.

## Why local order is essential

A record that switches between two q=4 regimes can require q=6 or q=8 when represented as one stationary model. That full-record order describes mixture complexity, not the local state dimension. Imposing q_full on each half creates extra local modes that can corrupt scalar matching, carrier MAC, and system geometry. Phase 0D therefore estimates q_full, q_first, and q_second separately.
