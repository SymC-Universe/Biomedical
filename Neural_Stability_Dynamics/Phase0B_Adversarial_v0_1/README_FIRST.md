# Neural Stability Dynamics - Phase 0B Adversarial Structure Identification v0.1

Phase 0A showed that the frozen SSI-COV candidate can recover poles and observable modal geometry when data are generated by the same stationary linear-Gaussian model class and true model order is supplied.

Phase 0B removes those conveniences.

This is a development/calibration phase, not the final synthetic admission test. It is frozen before execution so failures are informative, but its results may be used to design estimator/refusal rules and numerical thresholds for a separate untouched Phase 0C holdout. Phase 0C must then be frozen and run without further tuning before any TDBRAIN signal is admitted.

Primary questions:
1. Which structural features remain recoverable when model order is not supplied?
2. When do individual eigenvectors cease to be identifiable and subspace structure become the correct object?
3. How do mode crowding, non-normality, weak observability, short duration, white noise, and colored measurement noise degrade recovery?
4. Can order sweeps and split-record consistency distinguish genuine finite-dimensional modes from scale-free or nonstationary structure?
5. What diagnostics are required for a principled REFUSE outcome?

No diagnosis, participant workbook, treatment outcome, or historical desired neuro-spectrum placement is used.

Run from this folder in PowerShell:

```powershell
python local_runner.py
```

Outputs are written to `results/phase0b/`.
