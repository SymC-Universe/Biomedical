## User-facing authoritative artifacts not to edit automatically

When supplied as authoritative versions by the user, manuscript, supplement, figures, captions, and other publication text are governed by Protocol 55.2. This index may identify defects and required synchronization, but edits require the user's requested change scope.

## Release synchronization procedure

After any production capability change:

1. identify capability family above;
2. search code/docs/configs/manifests/README/manuscript/supplement/figures for descriptions;
3. compare every description to emitted production labels and semantics;
4. update program-maintained records automatically where the change merely restores frozen truth;
5. report proposed edits to authoritative user-supplied text for authorization;
6. rerun semantic validator;
7. record synchronization result in release manifest.
