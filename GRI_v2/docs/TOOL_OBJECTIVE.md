# Cancer Stability Atlas - Tool Discovery Objective

## Primary objective

Use the historical GRI/SymC biomedical work as **research ancestry rather than doctrine** to discover, test, and, if warranted, build reproducible tools that help cancer and systems-biology research.

The program is not required to recover a historical claim, preserve a historical scalar, validate biological chi, or retain the word "stability" in the final method. Variables, mathematical objects, model structure, and eventual tool function are selected by what prospective evidence supports.

The historical manuscript remains part of the provenance record. Its observations may motivate candidate measurements, its mathematics may supply useful constructions, and its failures may motivate safeguards, but none of its claims receives evidential priority.

The operating direction is:

**observation -> legitimate mathematics -> computation -> adversarial comparison -> useful scientific tool**

not:

**old claim -> accumulate supporting evidence**.

## What counts as a useful outcome

A successful outcome is any reproducible method that gives researchers information they did not already have from appropriate conventional baselines. Depending on what the evidence supports, that could be a:

- diagnostic or stratification method;
- multivariate decomposition or representation;
- cross-assay alignment diagnostic;
- regulatory-dependence or coupling estimator;
- predictor of perturbational response, state transition, drug response, progression, recovery, or another independently measured behavior;
- warning signal or model-selection criterion;
- experimental-design aid;
- interpretable benchmark showing that a proposed architecture adds no value beyond established methods.

The program should prefer a simpler useful tool over a more SymC-looking but weaker construction.

## Current biomedical discovery question

The current C1 methylation program is not a rescue test for historical GRI and is not a biological-chi search.

Its immediate purpose is to determine whether the exact methylation layer contains reproducible **modal + scalar + conglomeration** organization that survives construction-aware nulls, technical-mask robustness, patient-alignment tests, Hallmark-label tests, and the already-frozen purity/leukocyte composition attack.

The three views remain complementary:

- **modal:** mode-resolved covariance/eigenspectrum structure;
- **scalar:** explicit compression of the modal carrier when useful;
- **conglomeration:** gene/module/system-level organization.

A scalar does not replace modal structure or conglomeration. None of these static C1 quantities is biological chi.

If C1 reveals robust structure, the next question is not merely whether a manuscript claim can be promoted. The next question is **whether that structure can be converted into a useful, prospectively benchmarked method** and whether it improves over established alternatives on independent targets or data.

If C1 fails, the failure is retained and becomes information about which candidate mathematical constructions are not useful in this setting.

## What the tool should eventually do

Any promoted tool should predict, stratify, decompose, or otherwise improve inference for a prospectively defined biological quantity on held-out or genuinely independent data.

Candidate targets may include perturbational response, state transition, recovery behavior, drug response, progression, regulatory dependence, cross-layer coordination, or another independently measured outcome. The target and evaluation metric must be fixed before model evaluation for the relevant validation phase.

The tool should remain interpretable enough that performance can be traced to its mathematical carrier rather than only to an opaque aggregate score.

## Methodological inheritance from earlier SymC work

The inherited value is procedural and mathematical, not doctrinal:

- preserve distinctions among physically or biologically different measurements;
- preserve modal, scalar, and conglomeration views when all three are informative;
- define estimator provenance and uncertainty;
- prevent calibration data from serving as independent validation;
- compare against construction-aware nulls and established baselines;
- use effective generators, eigenspectra, network structure, transfer/dependence measures, or other mathematics only where their assumptions are satisfied;
- require genuine dynamic evidence before making dynamical claims;
- preserve failed hypotheses rather than retuning them into successes;
- allow a historically motivated construction to be abandoned completely when a better tool emerges.

## Historical GRI status

`CV/2` is a historical comparator. It is not chi and is not a required feature of any final tool.

The old substrate-capture, bandwidth, executor, critical-boundary, and therapeutic interpretations are not active assumptions. Any related concept must be re-earned using independently defined measurements and prospective tests.

Biological chi is optional, not a destination. It may be tested only if future data provide defensible same-coordinate Gamma and Omega measurements or calibrated estimators. A useful biomedical method that never contains chi is a fully successful outcome.

## Development ladder

### A. Static architecture map

Measure independent static coordinates from PanCanAtlas and matched data: variability, lineage/context, modal structure, and network/conglomeration organization. Do not collapse them into a master score.

### B. Multiomic context and dependence map

Add independently measured methylation, chromatin, protein, purity/composition, genomic, and other appropriate layers. Determine which structures are redundant, which are assay-specific, and which provide reproducible cross-layer information.

### C. Candidate tool extraction

From structures that survive prospective nulls and robustness attacks, define candidate diagnostics, decompositions, alignment measures, predictors, or experimental-design aids. Compare them directly with conventional methods addressing the same task.

### D. Dynamic benchmark where scientifically appropriate

Use genuine ordered perturbation or time-course data for questions involving propagation, recovery, memory, transition, or inheritance. Implement established comparators such as Dynamic Network Biomarkers and ordinary predictive/network baselines.

### E. Optional dynamical balance coordinate

Only if the data provide defensible, same-coordinate Gamma and Omega measurements or calibrated estimators, evaluate `chi = Gamma/(2 Omega)` as one candidate coordinate among others. Chi is never presumed to be the organizing answer.

### F. Predictive/model utility selection

Freeze candidate methods and compare them using held-out prediction, calibration, robustness, ablation, baseline superiority, and complexity penalties. Complexity and novelty must earn themselves.

### G. External validation

Freeze the selected tool and test it on data not used for architecture discovery or calibration. Failure remains a valid scientific outcome.

### H. Manuscript

Only after the evidence ladder closes do we write the replacement paper around what survived. The manuscript describes the useful method or negative result; the manuscript does not determine it.

## Success and failure

Success is not recovery of the old GRI narrative and not preservation of a SymC label.

Success is a reproducible mathematical/computational method that improves a scientifically relevant task, exposes a useful structure, or convincingly shows that a proposed structure does not add value beyond appropriate baselines.

If no SymC-derived or historically motivated construction improves inference beyond conventional methods, the correct conclusion is that those constructions did not add measurable value in the tested setting. The program then moves on using whatever was learned rather than defending the discarded formulation.
