# Chi Admission Rules

A quantity can enter the registry as an operational chi coordinate only if every hard gate below is true.

| Gate | Requirement |
|---|---|
| G1 | Numerator is a genuine dissipative/decay/recovery/relaxation rate. |
| G2 | Denominator term is a genuine intrinsic restoring/response frequency or compatible local rate. |
| G3 | Both quantities have compatible inverse-time dimensions before forming the ratio. |
| G4 | Both refer to the same projected biological coordinate/mode. |
| G5 | Measurements/calibrations are independently meaningful; one is not algebraically reconstructed from the other. |
| G6 | Neither quantity is derived from the downstream outcome later claimed to be predicted. |
| G7 | The factor of 2 and any other scaling arise from the governing model or a prospectively frozen calibration, not empirical tuning toward 1. |
| G8 | The model assumptions needed to interpret a scalar Gamma and Omega are stated and checked, including relevant memory/timescale issues. |
| G9 | Uncertainty is propagated to chi and regime labels are withheld if uncertainty spans relevant boundaries. |
| G10 | The mapping is tested on data with actual temporal/perturbational information before dynamical language is promoted. |

Failure of any hard gate means the quantity remains an ordinary atlas feature or candidate proxy. It is not chi.

## Explicit classification of CV/2

`CV/2` fails G1, G2, G3, G4, and G10 as a direct dynamical chi coordinate. It is therefore permanently classified in this branch as `historical_comparator`, unless a future independent calibration establishes a specific relationship to an admissible Gamma or Omega. Such a calibration would make CV/2 a possible estimator input, not retroactively turn the historical formula itself into chi.
