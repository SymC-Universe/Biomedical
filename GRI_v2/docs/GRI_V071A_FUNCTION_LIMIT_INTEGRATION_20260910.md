## 0. Purpose

This record operationalizes the v0.7.1A Functional Mapping and Natural Limit-Testbed Addendum for the current GRI program without changing any frozen or already-observed GRI result.

The addendum requires balanced learning about both:

- how a supported system/representation behaves where it works; and
- where, how, and why that representation degrades, transforms, refuses, or fails.

For GRI this creates a paired research target:

`GRI FUNCTION MAP + GRI LIMIT MAP`

Neither map is allowed to erase the other.

# 1. Research-mode classification

## 1.1 P0-D: discovery and mechanism mapping

Use P0-D for open-ended GRI work intended to understand the supported interior of the architecture, including:

- response surfaces across cancer types / cohorts / modalities;
- how scalar, modal/vector, conglomerate/system, and cross-component objects vary;
- coupling and redistribution across methylation, RNA, protein, genomic, and composition layers;
- alternative representations or transformations;
- candidate substrate relationships;
- candidate additional architectural objects;
- post-hoc diagnostics and visualizations;
- already-viewed data used to generate hypotheses.

P0-D may learn from existing TCGA evidence but may not convert those discoveries into confirmatory evidence for themselves.

## 1.2 P0-Q: qualification and controlled iteration

Use P0-Q for testing whether a candidate GRI System Model / Engine component is fit to face confirmation, including:

- known-truth synthetic systems;
- adversarial synthetic systems;
- previously observed failures;
- sensitivity analysis;
- identifiability analysis;
- negative controls;
- mutation tests;
- repeated-state equivalence tests;
- capacity/comparator qualification on already-viewed evidence;
- refusal-boundary qualification.

The currently frozen post-C1 adversarial sensitivity v2.2 is classified as **P0-Q**, not P1. It is a qualification/adversarial analysis of an already observed internal result and cannot promote that same result to prospective confirmation.

The future production Engine P2 qualification sequence inherits P0-Q evidence for engineering fitness but still requires separate P1 evidence for confirmatory scientific claims.

# 2. GRI Function Map

**Status:** current internal map is exploratory / internally supported, not externally confirmed.

The Function Map asks what happens where the current representation is supported.

## 2.1 Existing function-map evidence

Current internal evidence can already populate a development Function Map with the following non-causal objects:

- methylation spectral organization above construction-aware nulls;
- mode-resolved methylation structure and feature participation;
- patient-level methylation/RNA global geometry;
- Hallmark-level same-patient coupling where supported;
- context-sensitive changes after purity/leukocyte projection;
- internal predictive information from methylation Hallmark features beyond the two measured covariates used in the frozen comparator;
- an internally held-out relationship between frozen global geometry confidence and prediction risk;
- cancer-specific variation in representation performance, including PCPG as a recurrent transport stress case.

These are function-map observations, not automatically mechanisms.

## 2.2 Function-map questions now authorized for P0-D

Without changing current frozen science, future P0-D work may map:

1. which cancer types occupy similar or distinct global methylation/RNA geometry regions;
2. how modal concentration / effective rank changes across cancers and contexts;
3. whether several different internal modal organizations produce similar predictive risk;
4. where context adjustment changes geometry strongly versus minimally;
5. whether Hallmark structure adds interpretable organization beyond equally sized unstructured or alternative feature representations;
6. how model performance varies continuously across geometry, sample support, composition completeness, missingness burden, and platform history;
7. whether representation redundancy or redistribution explains stable predictions despite internal modal changes;
8. which observed states are common versus sparsely occupied within the available development evidence.

Any favorable region discovered after inspection remains P0-D until frozen and tested on untouched evidence.

# 4. Coverage architecture

The addendum defines four research roles. For GRI they are instantiated prospectively as follows.

| Research role | Current GRI status | Notes |
|---|---|---|
| `NOMINAL_FUNCTION` | **AVAILABLE INTERNALLY / NEEDS EXTERNAL CONFIRMATION** | Cancer/cohort regimes where the frozen architecture is evaluable and behaves within supported assumptions. |
| `PERTURBED_FUNCTION` | **PARTIAL** | Existing context-adjustment, technical-mask, missingness, and synthetic/adversarial tracks probe perturbed but still interpretable conditions. More biologically meaningful perturbational data remain desirable. |
| `BOUNDARY_OR_TRANSITION` | **ACTIVE CANDIDATE MAP** | PCPG, insufficient mapping/sample support, nonlinear-only scope, platform dependence, and reduction-adequacy failures contribute boundary candidates. These are not all physical transitions. |
| `RARE_NATURAL_LIMIT` | **NOT YET ADMITTED** | No case is labeled rare merely because it is unusual to GRI. Native rarity evidence and authenticity/confounding qualification are required first. |

These are research roles, not biological phases.

# 5. PCPG disposition under v0.7.1A

PCPG remains scientifically interesting because it repeatedly stresses the global transport/prediction representation.

However:

`RECURRENT_ENGINE_STRESS_CASE != RARE_NATURAL_TESTBED`

A future `RARE_NATURAL_TESTBED` designation requires independent domain-native evidence that the relevant PCPG state/event/phenotype is unusual by prevalence, tail position, accepted category, documented parameter combination, or another oncology-native criterion.

Selection may not be based on:

- closeness to a desired GRI coordinate;
- favorable or unfavorable residual alone;
- agreement with the architecture;
- model-generated severity;
- visual resemblance to an expected pattern.

Until that independent rarity gate is satisfied, PCPG should be described as a **recurrent stress case / candidate boundary regime**.

If a future rare-natural qualification is attempted, matched ordinary context and base-rate information should be preserved where available.

# 6. Pathway-specific independence map

Independence should now be recorded by the circularity pathway relevant to each claim rather than collapsed into one global label.

Minimum GRI dimensions:

- **data independence**;
- **cohort/system independence**;
- **outcome independence**;
- **parameter/tuning independence**;
- **method independence**;
- **Atlas independence**;
- **source/literature independence**;
- **temporal independence** where a temporal claim is attempted.

The controlling question is:

> Could the shared information on this pathway force the agreement being presented as evidence?

Examples:

- FINAL_HOLDOUT was internally independent of D4 for participant values at the frozen evaluation stage, but remains within the same broad TCGA program/cohort lineage and is therefore not external cohort independence;
- current TCGA methylation/RNA evidence is non-independent for validating an Atlas or Engine built from the same evidence;
- use of the same frozen mathematical coordinate transformation does not by itself destroy data independence;
- shared nuisance metadata can be acceptable when it cannot force the decisive agreement, but the shared path must remain visible.

Future MFR-10 and Atlas records should store these independence dimensions separately.

# 7. Function/Limit output extension for the future GRI Engine

The P2 output schema should add two explicit top-level groups.

## 7.1 `function_map_output`

Should contain, where supported:

- supported operating regime;
- observed response surfaces / trajectories / occupancy distributions;
- supported cross-component relationships;
- uncertainty;
- identifiability;
- reduction information loss;
- evidence class;
- discovery versus confirmatory status.

## 7.2 `limit_map_output`

Should contain, where supported:

- degradation/transition/refusal region;
- first failing component or relationship, if identifiable;
- scalar/modal/conglomerate reduction-adequacy status;
- rare-natural-testbed status when independently qualified;
- whether the limit appears physical, inferential, estimator-related, data-availability-related, or unresolved;
- relevant independence class;
- uncertainty/tolerance;
- current epistemic status.

The mature Tool should be able to distinguish at least:

- `WORKS_HERE`
- `STOPS_WORKING_HERE`
- `NOT_KNOWN_HERE`

These are outcome descriptions, not automatic biological-state labels.

# 8. Milestone balance check for current GRI state

## Question 1: Have we learned how the system behaves where the representation works?

**YES, internally, to a meaningful but incomplete degree.**

The program has mapped substantial static multiomic organization and internal held-out predictive behavior. It therefore should not become purely failure-seeking.

## Question 2: Have we meaningfully challenged where the representation stops working?

**YES, but the active post-C1 sensitivity is still needed.**

The program has retained multiple failures and stress cases, but current C1 robustness still needs the already-frozen adversarial sensitivity disposition.

## Balance decision

The immediate sequence remains:

1. finish the active P0-Q post-C1 sensitivity because that qualification gate is already frozen and unresolved;
2. in parallel continue non-heavy Function-Map organization of already observed development evidence;
3. after sensitivity closure, avoid launching an endless succession of boundary-only attacks unless a specific unresolved limit requires them;
4. shift a substantial P0 lane toward mapping the supported interior, especially representation occupancy, modal reorganization, compensatory/redistributive structure, and fair capacity-matched comparison;
5. preserve every new favorable region as P0-D until an independent freeze/confirmation path is defined.

This is not an equal positive/negative quota. It is a scientific-coverage balance.
