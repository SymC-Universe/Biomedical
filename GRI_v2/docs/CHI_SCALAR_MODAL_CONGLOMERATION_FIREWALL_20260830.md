# Chi scalar, modal, and conglomeration firewall

**STATUS: LOCKED PROGRAM-LEVEL INTERPRETIVE RULE**

Date: 2026-08-30

This document clarifies the meaning of `chi` across the research program without admitting any new biomedical chi coordinate and without modifying the frozen Stage C1 v2 biological contract.

## 1. Chi is not synonymous with critical damping

`chi` is a scalar coordinate symbol whose scientific interpretation is determined by the governing generator, derivation, dimensional structure, calibration, and evidentiary domain that produce it.

Critical damping is one licensed interpretation of one specific construction. For the second-order oscillator

`x_ddot + Gamma x_dot + Omega^2 x = 0`,

`chi_dyn = Gamma / (2 |Omega|)`

has the familiar underdamped / critical / overdamped response interpretation. That interpretation is licensed by that generator. It does not automatically follow the symbol `chi` into another model or domain.

A value of `chi = 1` therefore has no universal meaning. Unity is a special boundary only when the specific coordinate construction and governing model establish that boundary.

## 2. Minimum three-view architecture

The fullest description currently requires at least three complementary views:

1. **scalar view** - compressed coordinates and invariants;
2. **modal / vector view** - the mode-resolved carrier structure;
3. **conglomeration view** - integrated coupling, network, memory, environmental, and system-level organization.

The combined perspective means preserving the relationships among these views. It does not mean averaging them into one master score.

### Scalar view

Examples include eigenvalues, rates, frequencies, ratios, spectral gaps, entropy-derived concentrations, balance coordinates, or an admitted chi coordinate.

A scalar asks where the system lies in a deliberately compressed coordinate description. Compression is allowed to discard information and must never be mistaken for the complete state.

### Modal / vector view

Examples include right/left eigenvectors, eigenspaces, invariant subspaces, projectors, principal angles, participation weights, mode loadings, and other carrier-resolved structures.

The modal view asks what structure carries the observed behavior. Similar scalar spectra do not imply similar modal geometry.

### Conglomeration view

Examples include cross-layer mappings, coupled blocks, self-energy, memory kernels, network feedback, collective modes, environmental coupling, module organization, and sequences of transformations.

The conglomeration view asks how components and couplings organize into whole-system behavior. It is not automatically reducible to either one scalar or one mode.

## 3. Permanent firewalls

- Scalar similarity does not establish modal similarity.
- Modal similarity does not establish scalar inheritance.
- Neither scalar nor modal similarity by itself establishes whole-system organization.
- Conglomeration-level correspondence does not establish a particular scalar mechanism.
- A scalar can be useful even when there is no useful modal correspondence.
- Modal correspondence can exist when no scientifically useful chi coordinate exists.
- Conglomeration-level organization can be informative while scalar and individual-mode descriptions remain incomplete.
- Nonidentifiability in one view must be reported rather than repaired by borrowing certainty from another view.
- No master scalar may be created simply because scalar compression is convenient.

Disagreement among the three views is itself potentially informative and must be retained rather than averaged away.

## 4. Biomedical consequence

No biological chi coordinate is currently admitted in GRI v2.

The current biomedical quantities therefore remain what their constructions establish:

- `S_spec` is a scalar spectral-concentration summary, not chi;
- eigenspectra, eigenvectors, principal angles, and mode contributions are modal quantities;
- Hallmark/module architecture, cross-omic coupling, and the proposed regulatory-autonomy analysis are conglomeration or conditional-dependence quantities unless a separate scalar compression is explicitly defined and validated;
- regulatory autonomy is not automatically chi;
- static cross-omic structure is not damping, recovery, or a temporal trajectory.

The Gamma/Omega admission gates in `CHI_ADMISSION_RULES.md` apply specifically to the candidate **dynamical response coordinate `chi_dyn`**. They do not claim that all possible chi coordinates across all generators must equal Gamma/(2 Omega).

Any future non-dynamical or differently generated chi coordinate must receive its own prospectively frozen definition, derivation, dimensional/normalization justification, interpretation, uncertainty treatment, nulls, and admission gates before the name `chi` is used.

The biomedical tool is allowed to succeed entirely without chi.

The active architecture remains:

- modal structure as the underlying carrier;

Tool utility, calibration, external validation, and falsification decide what survives. Historical SymC naming does not.
