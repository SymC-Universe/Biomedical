# GRI Chi_bio static-to-dynamic bridge

**Date:** 2026-09-12  
**Status:** P0-D IDENTIFIABILITY / CALIBRATION DESIGN, NO CHI_BIO FORMULA FROZEN  
**Chi_bio status:** `NOT_ADMITTED`  
**Protocol authority:** General Cross-Project Research Protocol Final v0.7.4

## 1. Purpose

The current TCGA/C1 program is rich in static scalar, modal/vector, and conglomerate structure but lacks the time-resolved perturbation information needed to identify a dynamical regulatory operator directly.

This document defines the only defensible route currently visible for eventually placing all 32 TCGA cancers on a `Chi_bio` axis without pretending that static covariance is itself the dynamical operator:

```text
external dynamic / perturbational systems
        |
        +--> identify or qualify a candidate regulatory operator
        +--> compute candidate Chi_bio from the frozen operator definition
        +--> measure static observables available in both dynamic and TCGA systems
        |
        v
freeze a static estimator / proxy of the admitted-or-candidate Chi_bio
        |
        +--> test that estimator on held-out dynamic systems/states
        +--> quantify calibration, uncertainty, refusal, and transport limits
        |
        v
apply the frozen estimator to TCGA cancers
        |
        v
32-cancer Atlas placement with uncertainty
```

A static estimator is never automatically the same scientific object as `Chi_bio`. It is an estimator of a separately derived/validated coordinate only if the calibration path earns that status.

## 2. Why a bridge is scientifically plausible

### 2.1 Dynamic-network-biomarker theory

Chen et al. (Scientific Reports 2012, article 342, DOI `10.1038/srep00342`) and Liu et al. (Scientific Reports 2012, article 813, DOI `10.1038/srep00813`) derive early-warning behavior near a critical transition from a local noisy dynamical system.

In the discrete-time formulation used by Liu et al., the dominant eigenvalue of the Jacobian approaches modulus 1 as the system approaches the critical transition. The observable warning pattern is not the eigenvalue itself: fluctuations/covariances/correlations of variables become extreme in a characteristic leading network.

Therefore the literature supports this limited proposition:

> static or snapshot covariance structure can contain information about proximity to a dynamical boundary under explicit local-dynamics/noise assumptions.

It does **not** establish that a covariance statistic uniquely identifies the Jacobian, nor that H2, `S_spec`, H3a, or another current GRI statistic is already `Chi_bio`.

### 2.2 Native GRN unity boundary

Guo & Amir (Nature Communications 2021, DOI `10.1038/s41467-020-20472-x`) provide a separate gene-regulatory example in which the local protein-concentration dynamics reduce to

```text
dc/dt = beta0 [phi(c) - c]
A = beta0 (M - I)
M_ij = partial phi_i / partial c_j at steady state
```

and the steady state is stable while the maximal real part of the eigenvalues of `M` is below 1. In that model, unity is generated by the regulatory dynamics rather than inserted after observing data.

This strengthens the rationale for testing an operator-based system coordinate, while leaving open whether this exact `M` is the correct GRI object.

## 3. What TCGA can and cannot contribute

### TCGA can contribute

- high-dimensional covariance/eigenspectrum structure;
- scalar compressions traceable to modal structure;
- cross-layer methylation/RNA patient geometry;
- patient-specific and same-label conglomerate coupling;
- composition/context sensitivity;
- cancer-to-cancer heterogeneity;
- robustness under missingness, feature restriction, technical masking, modal ablation, and composition projection.

### TCGA cannot identify by itself

- temporal response direction;
- recovery/relaxation rate;
- a transition operator;
- a local Jacobian from dynamics;
- perturbation gain;
- causal regulatory direction;
- an operator-level unity crossing;
- recovery/resilience.

Therefore the first 32-cancer Atlas can use current coordinates now, but a biological `Chi_bio = 1` boundary cannot be attached to those cancers by direct relabeling.

## 4. Bridge qualification ladder

### B0 - shared-observable definition

Before calibration, define a set of observables that can be computed identically in both the dynamic calibration systems and TCGA. Candidate observable families may include:

- normalized covariance/eigenspectrum summaries;
- leading-subspace geometry;
- cross-layer geometry;
- Hallmark/module coupling;
- context sensitivity;
- modality-specific noise/variance quantities where source measurement supports them.

No observable is included because it correlates favorably with candidate Chi in the calibration data.

### B1 - operator truth or operator-qualified target

A dynamic source must provide either:

1. a candidate operator identifiable with stated assumptions and uncertainty; or
2. a known-truth synthetic operator; or
3. a perturbational response matrix with a justified mapping to the operator quantity being tested.

A static proxy cannot define its own target.

### B2 - calibration split

Dynamic systems/states used to select the estimator form are separated from those used to test transport/calibration. If data volume is too small for a meaningful split, the estimator remains exploratory and cannot be used to promote TCGA Chi values.

### B3 - standard estimator comparison

Any static estimator of Chi must be compared against simpler/natively established alternatives, such as:

- dominant covariance eigenvalue;
- variance/correlation DNB-style summaries;
- effective rank/spectral concentration alone;
- simple cross-layer geometry alone;
- regularized linear models using the same information budget.

A complex GRI estimator must add measurable calibration/transport value rather than merely rename known early-warning statistics.

### B4 - uncertainty and refusal

The estimator must produce uncertainty and may refuse when:

- calibration support is insufficient;
- the source lies outside representation support;
- scalar/modal/conglomerate disagreement is too large;
- operator truth is non-identifiable;
- uncertainty spans a candidate boundary.

### B5 - held-out dynamic validation

The frozen static estimator is evaluated against candidate Chi/operator truth on dynamic systems or states not used to select the estimator form or threshold.

### B6 - TCGA transport

Only after B0-B5 may the estimator be applied to the 32 TCGA cancers as an estimate of the frozen candidate Chi. The Atlas must retain:

- candidate versus admitted status;
- uncertainty;
- calibration domain;
- distance from training support;
- refusal status;
- scalar/modal/conglomerate disagreement.

### B7 - unity interpretation

Even a well-calibrated static estimator does not establish `Chi_bio = 1` as a biological boundary. Unity boundary meaning still requires CB14 and a separately defined native biological regime test.

## 5. Candidate calibration sources

### Source family 1: SCC25 cetuximab time course

`GSE98812` RNA-seq + `GSE98813` 450K methylation, 11 weekly treated and 11 matched PBS states.

Strengths:

- unusually close modalities to current GRI;
- ordered states;
- independent proliferation phenotype;
- same-state RNA/methylation;
- high value for first temporal falsification.

Limits:

- one cell line;
- pooled replicate structure;
- continued drug forcing;
- only 11 longitudinal states per arm;
- insufficient by itself for an unconstrained high-dimensional operator.

### Source family 2: source-qualified longitudinal IDH glioma families

Nomura et al. and CARE provide repeated patient states and richer single-cell/multiome context. They are valuable for transport/hierarchical questions but introduce representation-changing adapters and treatment heterogeneity.

### Source family 3: systematic perturbation datasets

Perturbation-response GRN inference literature shows that local response matrices/Jacobian-related structure can be estimated from systematic before/after perturbations under explicit local-steady-state assumptions. Such datasets may provide better operator-identification truth than a single passive trajectory even when their modalities are less TCGA-like.

## 6. Central anti-circularity rule

The bridge must follow:

```text
operator/dynamic truth -> frozen static estimator -> TCGA
```

not:

```text
TCGA pattern -> define Chi -> find dynamic story that matches
```

A candidate estimator may fail completely. That failure is retained as evidence that current static GRI observables do not identify the desired system-level coordinate.

## 7. Consequence for the requested 32-cancer scatter plot

A 32-cancer scatter relative to unity has three legitimate stages:

### Stage 1 - architecture Atlas, available now
Plot all cancers using established non-Chi coordinates. No biological unity boundary.

### Stage 2 - candidate-Chi estimator Atlas
After candidate derivation + bridge B0-B6, plot `candidate Chi_bio estimate` with uncertainty. A line at 1 may be shown only as **candidate/reference unity from the frozen model**, not a validated biological boundary.

### Stage 3 - admitted unity-boundary Atlas
Only after CB14 may the line be labeled as an empirically supported biological stability/regime boundary.

## 8. Current conclusion

The current evidence is sufficient to specify a credible route to 32-cancer Chi placement without overclaiming. It is not sufficient to compute those Chi values today.

The bridge removes the false choice between either abandoning the static TCGA architecture or pretending that static covariance is dynamics. Dynamic systems can calibrate/validate the latent system coordinate; TCGA can then be mapped only through a frozen, independently tested estimator.
