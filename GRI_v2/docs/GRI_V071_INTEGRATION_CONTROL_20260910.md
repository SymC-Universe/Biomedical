## 0. Scope and firewall

This document reorganizes the existing GRI evidence under the v0.7.1 program architecture. It is **not** a new scientific freeze, does not change the frozen Stage C1 scientific contract, does not alter P0/FINAL_HOLDOUT results, does not open or reinterpret unreturned post-C1 sensitivity results, and does not edit the authoritative manuscript.

Historical `CV/2` remains retired as biological chi. No biological chi is admitted. Static TCGA data do not establish damping, exceptional-point behavior, temporal inheritance, causality, treatment response, clinical utility, or a chi=1 optimum.

The v0.7.1 construction used here is:

`GRI System Model -> implemented by GRI Engine`

`GRI System Model + Independent Regulatory Substrate Atlas -> GRI Tool`

`Validated GRI System Model + Independent Regulatory Substrate Atlas + Prospective Validation -> Predictive GRI Tool`

The System Model is the scientific representation. The Engine executes it. The Atlas is separately constructed empirical memory and is read-only with respect to System Model / Engine rules. Mechanism and predictive validity remain earned properties, not consequences of naming.

# 4. Working GRI System Model / Engine map

**Status:** working migration representation, not a new scientific freeze.

## 4.1 Measurement layer

Potential measured inputs already present in the development lineage include methylation beta values, RNA expression-derived Hallmark states, ABSOLUTE purity, leukocyte fraction, genomic context, and RPPA context. Future modalities may be admitted only with their own provenance and validity gates.

Measurement is not model inference.

## 4.2 Scalar starting structure

Current admitted scalar-like summary:

- methylation normalized spectral organization `S_spec = 1 - H_norm` relative to its construction-aware null.

`S_spec` is **not biological chi**. A scalar may compress an aspect of organization but may not replace modal, conglomerate, or cross-component structure by assumption.

Historical `CV/2` is excluded from the active biological model.

## 4.3 Vector/modal starting structure

Current admitted modal objects include:

- methylation sample-space eigenspectrum;
- retained top modes and mode-to-probe contribution traceability;
- principal-angle / subspace diagnostics;
- RNA and methylation mode-resolved shared/private structure where interpretable.

Global modal/shared-private decomposition is an established primitive and carries no novelty claim by itself.

## 4.4 Conglomerate/system organization

Current conglomerate organization includes Hallmark-level RNA and methylation representations, within-layer module topology, same-Hallmark patient coupling, and system-level patient geometry across layers.

Hallmark labels are an interpretive/biological organization layer. Strong per-cancer Hallmark-semantic sharing was not promoted and remains a failure/refusal boundary.

## 4.5 Cross-component structure

Internally supported static relationships include:

- methylation organization beyond probe-marginal construction null;
- methylation/RNA patient-geometry alignment;
- patient-specific Hallmark coupling;
- context-sensitive changes under purity/leukocyte projection;
- an internally held-out relationship between frozen global-geometry confidence and prediction risk.

Not supported by the present data:

- temporal substrate inheritance;
- dynamical recovery;
- causal methylation-to-RNA regulation;
- damping or exceptional-point dynamics;
- clinical decision validity.

## 4.6 Working Engine output classes

A future GRI Engine should emit separate, machine-readable classes rather than one omnibus score:

1. **measurement status**: provenance, coverage, missingness, platform, sample identity;
2. **scalar output**: admitted compressed coordinates with null/floor and adequacy status;
3. **modal output**: eigen/subspace structure, mode contributions, uncertainty/stability;
4. **conglomerate output**: module/system organization and support;
5. **cross-component output**: patient alignment/coupling plus context attacks;
6. **reduction-adequacy output**: where scalar/global summaries cease to be adequate;
7. **Atlas comparison**: read-only contextual match against a frozen Atlas version;
8. **classification/admission/refusal**: supported / caution / refuse / not evaluable states;
9. **prediction output**: only for a separately frozen prediction record;
10. **epistemic status**: discovery, internal holdout, post-hoc/adversarial, confirmatory external;
11. **provenance**: exact Engine/System Model/Atlas versions and hashes.

Mechanism must remain a separate earned interpretation, never an automatic Engine field inferred from structural agreement alone.

# 6. Regulatory Substrate Atlas v0.1 architecture

**Status:** schema/independence plan only. No Atlas is declared validated or locked by this document.

The Atlas answers: where has a comparable regulatory state been observed, under what biological/technical conditions, and with what uncertainty? It does not tell the Engine what it should find.

## 6.1 Minimum record fields

Each Atlas record should contain, where applicable:

- entity/cancer/cohort identity;
- tissue / normal-versus-tumor / subtype context;
- condition and acquisition context;
- measurement modality;
- raw observable identity and units/conventions;
- scalar coordinate(s), if admitted;
- vector/modal features;
- conglomerate/system features;
- cross-component relationships;
- uncertainty and sample size;
- source and extraction method;
- preprocessing/harmonization record;
- known confounders;
- platform/batch information;
- evidence tier;
- selection rule/status;
- reduction-adequacy status;
- failure/refusal boundary if observed;
- discovery versus confirmatory status;
- provenance/hash;
- independence grade for any validation use;
- claim ceiling.

Do **not** collapse methylation, RNA, chromatin, protein, composition, genomic, spatial, single-cell, clinical, and other modalities into one omnibus score merely to make an Atlas row simpler.

## 6.2 Initial independence ledger

| Reference family | May populate Atlas context? | Independence grade for validating current GRI Engine | Reason |
|---|---|---|---|
| Current TCGA PanCanAtlas methylation used in C0/C1/P0 | Yes, as development/historical reference | `NON_INDEPENDENT_FOR_ENGINE_VALIDATION` | Same data lineage contributed directly to System Model/Engine development and internal evaluation. |
| Current TCGA RNA / Hallmark representations | Yes, as development/historical reference | `NON_INDEPENDENT_FOR_ENGINE_VALIDATION` | Used in architecture construction, cross-layer evaluation, and prediction targets. |
| TCGA ABSOLUTE purity / leukocyte fraction | Yes, as context/nuisance reference | `NON_INDEPENDENT_FOR_ENGINE_VALIDATION` for current Engine claims | Used in development context attacks and predictive evaluation. |

| Single-cell/spatial/proteomic external reference family | Candidate | To be assigned before use | May test cell-composition and cross-scale structure if independently sourced and frozen. |

The current TCGA evidence can help describe the Atlas development landscape, but it cannot serve as independent Atlas validation of an Engine built from the same evidence.
