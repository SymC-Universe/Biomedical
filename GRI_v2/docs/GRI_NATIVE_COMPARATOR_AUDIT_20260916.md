# GRI native-comparator audit

**Date:** 2026-09-16  
**Status:** CURRENT COMPARATOR/NULL-REFERENCE MAP  
**Program rule:** a `NO_NATIVE_COMPARATOR` disposition requires a good-faith same-question comparator search. It does not mean that an irrelevant benchmark must be forced onto a descriptive or identifiability question.

## Purpose

Different parts of GRI ask different scientific questions. A fair comparator for a predictive model is not automatically a fair comparator for a topology map, an inverse-identifiability problem, or a representation-admission gate. This audit records which comparison role is already present and where a same-question comparator still must be prospectively identified.

No row below changes a frozen analysis or retrospectively inserts a comparator into a completed result.

## Comparator status vocabulary

- `CURRENT_INTERNAL_COMPARATOR` — the frozen analysis already contains a meaningful same-question comparison.
- `NULL_REFERENCE_SUFFICIENT_FOR_CURRENT_DESCRIPTIVE_CLAIM` — the present claim is descriptive/organizational and is bounded by construction-aware nulls or references rather than a competing predictive method.
- `COMPARATOR_REQUIRED` — a stronger future claim cannot be promoted without a fair comparator.
- `GOOD_FAITH_SEARCH_REQUIRED` — the relevant method class must be searched before concluding that no native comparator exists.
- `NO_NATIVE_COMPARATOR_NOT_YET_ESTABLISHED` — there may be no direct comparator, but that absence has not been demonstrated well enough to claim it.

## `NO_NATIVE_COMPARATOR` firewall

GRI must not use `NO_NATIVE_COMPARATOR` as a convenience label meaning “the proposed method is unusual.” Before that label is allowed for a promoted task, the record should contain:

1. the operational question being answered;
2. the measurement type and population/system;
3. the class of established methods that could answer the same question;
4. a search of primary literature/software for those methods;
5. reasons each candidate is same-question, adjacent-question, or irrelevant;
6. the strongest fair comparator if one exists;
7. if none exists, a dated `NO_NATIVE_COMPARATOR` conclusion with the search terms/sources preserved.

An unrelated biomarker, generic classifier, or deliberately weak baseline does not satisfy MFR-14 simply because it produces a numerical comparison.

## Current conclusion

The existing GRI internal descriptive and admission results are not invalidated by the absence of a universal comparator because many current claims are topology, null-reference, or identifiability claims rather than competitive prediction claims. However, **future promotion is comparator-sensitive**. In particular, restoration inference, representation transport, and any clinical or external P1 task require a fresh same-question comparator audit before the decisive outcome is opened.

Therefore the current program state is not `NO_NATIVE_COMPARATOR`. It is a mixture of existing internal comparators, adequate descriptive null/reference constructions, and prospectively unresolved comparator obligations.
