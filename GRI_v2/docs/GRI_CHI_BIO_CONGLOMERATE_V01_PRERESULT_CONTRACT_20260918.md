# GRI Chi-bio conglomerate v0.1 pre-result contract

**Date:** 2026-09-18  
**Status:** PRE-RESULT / FROZEN CARRIER CONTRACT  
**Purpose:** assemble already-earned GRI evidence into a patient/system-level capital-Chi biological architecture without presuming a universal scalar, damped oscillator, or unity boundary.

## 1. Scientific object

Capital Chi-bio is treated here as a **multirepresentational biological stability architecture**, not as a scalar target.

The initial carrier is a block-structured profile:

[
Chi_{bio}^{(j)} = {R_j, S_j, E_j, G_j, P_j, M_j, T_j, Q_j}
]

where the blocks are:

- **R — RNA/regulatory organization**
- **S — methylation/substrate organization**
- **E — embedding/context and measured composition**
- **G — genomic context/constraints**
- **P — protein/phosphoprotein coupling**
- **M — modal/vector organization**
- **T — temporal/operator behavior where ordered data exist**
- **Q — uncertainty, technical robustness, identifiability, and refusal metadata**

This notation is organizational only. The blocks are not added, averaged, or weighted into a master score.

## 2. Foundational firewalls

1. No block is renamed biological chi.
2. No scalar reduction is required.
3. No damped-oscillator model is assumed.
4. No global Chi-bio = 1 boundary is assumed.
5. Static TCGA measurements do not inherit temporal meaning.
6. Missing modalities remain missing; v0.1 does not impute across assay classes.
7. Outcome labels, survival, treatment response, recurrence, or drug sensitivity do not define the carrier.
8. Failed/refused historical representations remain visible as Limit-Map information.
9. Existing opened TCGA partitions are development evidence for any new conglomerate version, not untouched confirmation.
10. Any diagnostic or predictive head is downstream of this carrier and must be frozen separately before evaluating its target.

## 3. Relationship structure

The carrier may record relationships already supported by prior work, including cross-layer geometry, patient alignment, modal organization, technical-mask sensitivity, composition sensitivity, and temporal/operator behavior. Untested relationships are explicitly UNTESTED.

The v0.1 carrier does not infer causal direction from association.

## 4. Synthetic known-truth gate

Before real biological outcomes are used, the implementation must pass synthetic tests showing that:

- block identities are preserved;
- row/sample identity is preserved;
- within-block affine rescaling does not alter standardized block geometry;
- missing blocks remain explicitly missing;
- no scalar Chi-bio output is produced;
- leave-one-block-out diagnostics identify which representation was removed without silently renormalizing the remaining blocks into a master score;
- pairwise block geometry is symmetric and bounded where defined.

Passing this gate validates implementation behavior only. It does not validate biology.

## 5. Real-data assembly gate

After synthetic closure, the next task is to bind each block to frozen GRI source artifacts and produce a provenance table with:

- source artifact / run / commit;
- sample identity key;
- feature definition;
- preprocessing authority;
- uncertainty or robustness field;
- evidence class;
- whether the quantity is local, embedded/contextual, modal, temporal, or limit/refusal information.

No outcome-dependent feature selection is allowed during this binding step.

## 6. Tool objective

The downstream tool must be tested in at least two separate roles:

### Diagnostic head
Classify or stratify an independently defined current biological state from the frozen Chi-bio carrier.

### Predictive head
Predict an independently defined future/held-out biological outcome from the frozen carrier.

The carrier may succeed even if no scalar summary exists. A diagnostic/predictive head may be useful even if some blocks are absent, but any such reduced-input mode must be frozen and validated as its own operating mode.

## 7. Finish-line sequence

1. synthetic carrier validation;
2. frozen real-data block/provenance assembly;
3. internal development ablation against the retained predictive core and fair conventional baselines;
4. freeze diagnostic task;
5. freeze predictive task;
6. external independent validation;
7. immutable tool/manuscript release.

This contract does not choose a clinical endpoint or treatment rule. Those remain separate science-changing freezes.
