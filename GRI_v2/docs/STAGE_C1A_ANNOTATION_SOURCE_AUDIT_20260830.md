## Mechanical failure and repair record

The first source-gate attempt failed during modern R dependency resolution before either frozen source was used biologically. The historical annotation package depends on `minfi`, while the current dependency graph pulls the annotation package back through `minfi`, producing a circular installation path.

This was classified as **mechanical, not scientific**. The repair did not alter the approved annotation source, genome build, regulatory definitions, many-to-many mapping rule, SNP rule, cross-reactive source, primary/robustness distinction, or claim ceiling.

The repaired extractor reads only the required `DataFrame` objects directly from the exact frozen tarball using `S4Vectors`. A regression test forbids reintroduction of the failed `minfi` installation path.

Post-repair full Python CI passed, and the repaired C1A source workflow then passed end to end.

## Artifact-level verification

The source-gate artifact generated by the successful run contains the exact source tarball, Chen source, portable annotation export, compact cross-reactive ID list, acquisition JSON, object inventory, and source summary.

Independent local inspection confirmed that the file hashes in the source-gate evidence agree with the recorded values. A packaging-only defect was found in the first successful artifact: its `SHA256SUMS.txt` used the CI working-directory prefix even though GitHub artifact extraction flattens that top-level directory. The file bytes and hashes were correct; the manifest path names were not extraction-root-relative. The workflow is repaired prospectively so the next source artifact validates with `sha256sum -c` after ordinary extraction.

The Windows handoff from the same successful run independently validated all internal hashes. A second packaging issue was also found before user execution: the README promised a one-picker workflow while the driver still prompted for three already-bundled compact files. The driver is repaired so the final handoff prompts only for the existing local methylation TSV and auto-selects its bundled frozen annotation files.

Neither packaging repair changes scientific settings or source content.
