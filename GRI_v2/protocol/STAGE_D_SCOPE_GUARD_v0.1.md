# Stage D Scope Guard v0.1

Status: FROZEN BEFORE STAGE-D BIOLOGICAL OUTCOME INSPECTION

Stage D is part of the same GRI manuscript only if it remains a direct evidentiary extension of the current static architecture and predictive-transport result.

## In-scope additions

- real perturbation-withdrawal-recovery analysis;
- temporal recovery model where actual time support exists;
- methylation-to-RNA/chromatin perturbation prediction;
- scalar/modal/conglomeration recovery descriptions;
- relationship/uncertainty/refusal states;
- independent experimentally ordered transformation challenge;
- transformation-resistance contrast;
- capacity-matched, scramble, technical, nonlinear, and context-depth controls;
- exact provenance/reproducibility records.

## Out-of-scope for this manuscript unless a separate future protocol is approved

- clinical diagnosis/prognosis/treatment-response claims;
- patient survival endpoint fishing;
- retrospective tumor-stage pseudotime;
- a newly invented biological chi coordinate;
- exceptional-point claims from static omics;
- arbitrary weighted stability indices;
- unvalidated causal language;
- ad hoc subtype mechanism stories chosen from Stage-D outcomes;
- adding unrelated omics simply because they are available.

## Paper-integration rule

Stage D may remain in the same paper if it answers the current paper's central limitation: static correspondence alone cannot establish perturbation response, recovery, or inheritance-style directionality.

If Stage D grows into a separate clinical or mechanistic program whose claims no longer depend directly on the frozen static architecture, it must split into a separate paper rather than making the current manuscript unbounded.
