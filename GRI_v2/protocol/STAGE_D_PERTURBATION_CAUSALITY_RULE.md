# Stage D Perturbation Causality Rule

An intervention on methylation that changes RNA/chromatin strengthens directional evidence relative to static association, but causal interpretation still depends on intervention specificity, off-target effects, matched controls, and whether generic cell-state changes explain the response equally well.

Stage D therefore distinguishes `PERTURBATION_PREDICTION_SUPPORT` and `SUBSTRATE_INFLUENCE` from stronger inheritance language until specificity controls are satisfied.
