# Stage D Result Integration Rule v0.1

When Stage-D results return, manuscript language must follow the highest gate actually satisfied, not the intended hypothesis.

Examples:
- D-P1 only -> report perturbation/influence only.
- D-P2/D-P3 -> report predictive transport under the tested context; do not claim recovery if D-P4 fails.
- D-P4 -> report recovery/persistence association/prediction in the tested perturbation system; do not claim malignant-transition generalization if D-P5 fails.
- D-P5 -> report independent transformation/resistance generalization; do not claim causality if D-P6 is not met.
- D-P6 -> report intervention-specific supporting inheritance evidence only within the tested systems; no universal law or clinical utility follows automatically.

Every failed higher gate remains visible in the abstract/discussion if it materially bounds the promoted claim.
