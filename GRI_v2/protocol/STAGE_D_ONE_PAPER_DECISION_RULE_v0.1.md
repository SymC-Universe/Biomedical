# Stage D One-Paper Decision Rule v0.1

Stage D is intentionally being developed as an extension of the current GRI manuscript, but inclusion is conditional on scientific coherence rather than page count.

Keep Stage D in the same paper if:
1. D1/D2 directly test the current manuscript's stated limitation that static correspondence cannot establish perturbation response/recovery;
2. D3/D4 are used only as independent challenges of signatures frozen from D1/D2;
3. the resulting claim remains a single story from static architecture -> predictive transport -> perturbation/recovery -> independent transformation challenge;
4. the manuscript can report failures and limitations without hiding them in supplementary material.

Split Stage D into a separate paper if:
1. clinical endpoints become a major aim;
2. extensive new mechanistic branches are added that do not depend on the static GRI architecture;
3. D3/D4 require substantial post-hoc model development;
4. the perturbation program becomes a standalone methods paper with a different central claim.

This rule is frozen before Stage-D outcomes so paper placement cannot be chosen solely because the results are favorable or unfavorable.
