## 2. Occupancy map, current state

The current evidence does not justify a continuous biological state-space atlas with calibrated external boundaries. It does support an internal occupancy description across the evaluated TCGA cancers.

### 2.1 Broadly occupied internal region

The currently occupied internal region is characterized by:

- nontrivial within-layer RNA and methylation organization;
- broad methylation/RNA patient-geometry alignment;
- stronger leading-mode than late-mode correspondence;
- patient-specific Hallmark coupling that is stronger than label-specific semantic evidence;
- retained architecture after a limited purity/leukocyte context projection in most evaluable cancers;
- heterogeneous but often useful methylation-to-RNA predictive information.

This is an empirical organization landscape, not a dynamical stability basin.

### 2.2 Context-sensitive interior

The Function Map must preserve regions where the representation still yields usable structure but context materially changes magnitude or interpretation. Examples include:

- immune/inflammatory programs under purity/leukocyte projection;
- cancer-specific variation in global geometry;
- differences in leading-mode concentration;
- cancers where semantic label specificity is weak despite strong global shared geometry;
- cancers where predictive performance remains useful but weaker than the internal median.

These states should be represented as `WORKS_HERE_WITH_CONTEXT_SENSITIVITY`, not collapsed into either full support or failure.

## 3. Compensation, redistribution, and alternative internal organizations

v0.7.1A explicitly asks whether several internal organizations can produce similar system outcomes and whether compensation, redundancy, redistribution, or reorganization occurs.

Current GRI evidence supplies **candidate** leads but not confirmed mechanisms:

1. **Global versus semantic redistribution:** strong global patient geometry can coexist with weak Hallmark label-specific evidence. This suggests that shared structure may be distributed across modules rather than requiring one-to-one semantic matching. Status: `P0_D_CANDIDATE`.
2. **Leading-mode concentration:** global alignment is strongest in leading subspaces, suggesting that much shared organization may be concentrated rather than uniformly modal. Status: `P0_D_CANDIDATE` until post-C1 ablation sensitivity returns.
3. **Composition-sensitive redistribution:** immune/inflammatory modules change more under purity/leukocyte projection while broader topology persists. Status: `P0_D_CANDIDATE` for context redistribution, not causal compensation.
4. **Predictive equivalence across different internal organizations:** cancers can show useful prediction despite different semantic/global geometry profiles. This should be mapped explicitly rather than assuming one structural route to good prediction. Status: `P0_D_OPEN`.

No use of the word compensation here implies a demonstrated biological feedback mechanism.

## 4. Information loss inside the functioning region

A Function Map must record what reductions discard even before they fail outright.

### 4.1 Scalar compression

`S_spec` compresses a methylation eigenspectrum into normalized spectral concentration. It necessarily discards:

- individual eigenvalues beyond their entropy contribution;
- eigenvectors/mode identity;
- mode-to-probe traceability;
- cross-layer orientation;
- module identity;
- patient-specific coupling patterns.

Therefore `S_spec` can be `WORKS_HERE` as a spectral concentration summary without being sufficient as a full architecture representation.

### 4.2 Global CKA compression

Global CKA compresses cross-layer geometry and discards or obscures:

- which modes carry the alignment;
- which Hallmarks or features contribute;
- semantic correspondence;
- possible cancellation/redistribution across subspaces;
- causal direction;
- spectrum-dependent null-floor structure if raw CKA is compared across cancers without correction.

The Function Map therefore treats global CKA as an established global-geometry primitive, not a complete system description.

### 4.3 Hallmark aggregation

Hallmark PC1/module summaries discard within-module feature heterogeneity and may be unsupported where methylation source mapping is inadequate. The five promoter-core Hallmarks already structurally refused in C1 remain visible as information/support limitations.

## 5. Current Function Map research questions for P0-D

These may be explored on already-viewed/internal evidence without pretending to be confirmatory:

- How does leading-mode concentration vary across cancer types and technical tracks?
- How much of global geometry can be reconstructed from the first one, three, or several modes?
- Which cancers share similar global geometry but different semantic/module coupling?
- Which cancers share similar predictive risk despite different modal organizations?
- How does purity/leukocyte projection move each cancer within the internal architecture landscape?
- Which modules are consistently context-sensitive versus context-robust?
- Does the technical-mask track alter only magnitude, or does it reorganize modal orientation?
- Where do scalar summaries preserve ordering while modal detail changes substantially?
- Can cancers be grouped by architecture without using downstream outcome labels?
- Which current `WORKS_HERE` regions remain stable under the frozen post-C1 sensitivity attacks?

Any favorable subgroup or pattern found through these questions remains P0-D until a later independent freeze/test.
