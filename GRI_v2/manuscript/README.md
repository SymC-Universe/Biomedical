## Editing rule

The manuscript may evolve incrementally in GitHub. A new analysis does not require an immediate full-manuscript rewrite, but any result that materially changes a claim, limitation, figure, interpretation, or epistemic class must be reflected in one of three places:

1. the integrated living draft, if the narrative should change now;
2. a clearly indexed current section file, if that section is still under active evidence development;
3. the reconciliation ledger, if the evidence is real but full prose integration should wait for a consolidation pass.

Historical manuscript copies are not authoritative merely because they are older, formatted for submission, or stored locally. Final submission authority will be established later by an explicit manuscript freeze and line-by-line reconciliation.

## Numerical and figure rule

Numbers, table entries, and figure labels are not promoted from memory or an older manuscript. Before final insertion they must trace to a frozen source artifact or deterministic derivation with version/run identity, uncertainty/tolerance where material, and evidence class.

The current figure rebuild specifically retires historical language that overstates the evidence, including `Critical Failure`, `Forensic Capture`, and unresolved `Energy Omega` axes unless a later native derivation independently earns them.

- Internal P0-D/P0-Q evidence is not relabeled untouched P1 because it appears in the manuscript.

## Why the manuscript lives here

The repository, not assistant memory or an old local manuscript copy, is the continuity anchor. We can therefore improve the paper as evidence closes without repeatedly reconstructing which draft was current. The file can remain visibly incomplete for as long as the science requires.
