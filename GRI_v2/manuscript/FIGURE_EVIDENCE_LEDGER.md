## Rule

A figure panel is not allowed into the final manuscript merely because it is visually persuasive or appeared in the historical submission. Each panel must identify its scientific purpose, exact source, evidence class, statistic/provenance state, and caption ceiling.

`SOURCE_RECONCILIATION_REQUIRED` means the concept is justified but the final plotted values have not yet been traced line by line to the frozen artifact. That state is preferable to reconstructing a familiar number from memory.

## Plot-generation provenance requirements

For each quantitative panel before submission freeze, record:

```text
figure_id
panel_id
source_artifact_or_file
source_sha256_or_git_sha
source_fields_or_rows
plot_generator_path
plot_generator_commit
filter/QC rule
uncertainty definition
axis transformation
caption evidence class
```

If a panel is deterministic from a frozen result, regenerating its artwork is mechanical. Changing the filter, state definition, rank, threshold, feature universe, or scientific comparison to improve the panel is not mechanical and must stop for scientific review.

## Visual-design principle

The visual hierarchy should make the actual science easy to read:

1. what is measured;
2. where structure functions;
3. where compression/refusal fails;
4. what is independent versus reused;
5. what remains unknown.

The figures should not make a scalar appear inevitable when the evidence currently says it is not admitted.
