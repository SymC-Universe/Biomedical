## Why this notice exists

This note is not a request to replace the live submission or to bypass peer review. It asks that the handling editor be aware, before an editorial decision, that a materially corrected version is being prepared and that the author intends to submit that corrected version at the appropriate revision/resubmission stage.

## What remains supported

The revised program still supports a narrower and more defensible scientific core:

1. cancer exhibits reproducible multi-layer molecular organization that can be mapped under explicit sampling, composition, missingness and provenance controls;
2. scalar, modal/vector, cross-layer and system-level representations carry different information and should not be conflated;
3. the historical GRI scalar is useful as development history but does not earn a biological damping interpretation;
4. a block-preserving architecture can be tested for incremental information, transportability and refusal without forcing a universal scalar;
5. the framework now defines explicit experiments and external tests that can falsify stronger dynamic or predictive claims.
