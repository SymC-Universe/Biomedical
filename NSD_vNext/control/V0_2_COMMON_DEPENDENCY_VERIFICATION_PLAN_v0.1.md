# NSD v0.2 Common-Dependency Verification Plan v0.1

**Status:** PREFREEZE DESIGN / NO EXECUTION AUTHORITY

The shared-dependency register is not satisfied by reproducing the same production calculation twice. Each required truth premise must have a second verification route before exact packet APQ can close.

For N-B1 generator-family labels, the final packet must include an analytic family certificate or independently implemented generator check showing why each C-preserving and C-refusing truth has its frozen semantic label. The verifier must not use fitted C1Q/C1Q-RS quality to assign family membership.

For sampling/alias contracts, the verifier must independently calculate the continuous-to-sampled mapping and confirm the declared alias-safe or ambiguous status. At least one adversarial ambiguous case must be checked from the mathematical sampling relation rather than the production estimator.

For N-B2/N-B3 finite-time targets, critical target values must have a reference route distinct from the production target evaluator. At minimum this covers spectral abscissa, metric finite-time gain, similarity invariance, ordered time-varying propagators, and the global peak check. Simple analytically soluble Function cases should be included so the reference route has a known anchor.

Shared numerical libraries and environment components must be recorded. A second check that merely calls the same production function through another wrapper is not independent verification.

Every reference result records method identity, code/dependency/environment identity, target/case identity, expected relation, numerical-only comparison rule, and status. Failure of a required shared premise blocks packet APQ; it is not repaired using scientific result values.
