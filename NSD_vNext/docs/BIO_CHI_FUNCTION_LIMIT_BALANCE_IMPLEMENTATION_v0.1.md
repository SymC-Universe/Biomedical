## Interpretation

The Function Map asks how broadly the intended one-mode continuous-lineage representation behaves coherently when it is actually the correct truth family. It is not an empirical claim that those synthetic cells occur equally often in neural systems.

The Limit Map continues to answer where the representation can be fooled, becomes nonidentifiable, changes family, aliases, or should refuse. A Limit Map result may narrow the Function Map claim. It does not erase supported interior behavior elsewhere.

The combined scientific object is therefore:

[
	ext{supported interior}
+
	ext{meaningful perturbation}
+
	ext{transition / boundary structure}
+
	ext{documented limits}.
]

That combined object, rather than either success-only or failure-only evidence, is the intended Bio Chi qualification picture.
