# Bio Chi Integrated N-B1 Admission/Refusal Architecture Plan v0.1

**Status:** CANDIDATE / NOT APQ-QUALIFIED / NOT FROZEN  
**Date:** 29 September 2026  
**Governed by:** SymC General Operations Manual v1.0  
**Lifecycle:** Stage 3 plan construction following completed Profile Function/Limit calibration

## Purpose

Construct a prospective conjunctive admission architecture for a candidate local biological chi without allowing any one favorable diagnostic to self-license the coordinate.

The completed Profile Function/Limit calibration establishes that practical identifiability and semantic model admissibility are orthogonal. Therefore profile likelihood is restricted to the practical-identifiability role.

## Candidate gate families

The architecture will preserve independent evidence channels for:

1. provenance and sampling identity;
2. native dynamical family admissibility;
3. model order / multiplicity;
4. memory and substrate closure;
5. stationarity / temporal consistency;
6. alias and paired-sampling lineage;
7. practical identifiability via profile likelihood;
8. numerical/search integrity;
9. uncertainty and boundary behavior;
10. optional local-chi derivation only after all required upstream gates pass.

No numerical cutoff is proposed in this plan version.

## Refusal semantics

Refusal is an admissible scientific output. A recording or known truth may retain modal/vector/system information even when local chi is refused.

Candidate refusal classes include:

- family unresolved;
- structural order unresolved;
- memory/closure unresolved;
- nonstationary;
- alias/sampling lineage unresolved;
- practically nonidentifiable;
- numerical boundary/nonregular;
- insufficient information;
- incompatible evidence across independent gates.

A later APQ-qualified plan must distinguish logical refusals from empirical tolerances.

## Anti-circularity rule

The completed 72-row Profile Function/Limit packet may motivate gate roles but may not be used to tune a new admission threshold that is then scored on the same rows.

Any numerical tolerance intended for future admission requires a prospectively separated qualification population and later independent evaluation.

## Success criterion for the architecture

The target is not maximum admission rate.

A useful architecture should:

- admit representative valid cases when information is sufficient;
- refuse known semantic violations even when a compact C fit exists;
- refuse weak/nonregular valid cases when the local coordinate is not practically supported;
- preserve broader Chi/system information when scalar admission fails;
- expose which gate caused refusal;
- remain reproducible under the declared sampling and uncertainty contract.
