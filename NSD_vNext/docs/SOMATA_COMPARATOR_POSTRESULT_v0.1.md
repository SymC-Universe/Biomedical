## Scope

This was the first prospectively frozen, matched-information comparison between:
- NSD A0/A1/A2 state-space competition;
- SOMATA 0.5.6 iOsc+ with one/two oscillators and package-native knee selection.

Both tools received the exact same 120 Hz standardized signal generated by deterministic polyphase resampling of the already-frozen 256 Hz known-truth realization.

No manual post-result model selection or scenario-specific tuning was used.

This audit does **not** rank the tools.

## Important sampling/preprocessing finding

The matched 120 Hz transform changed NSD behavior relative to the earlier native 256 Hz adequacy map on some adversarial conditions.

At 256 Hz, the earlier frozen adequacy map reported:
- colored observation noise -> A1 in 3/3;
- nonoscillatory AR(1) -> A0 in 3/3.

On the resampled 120 Hz comparator signal:
- colored observation noise -> A2 in 3/3;
- nonoscillatory AR(1) -> A2 in 3/3.

White noise remained A0 in 3/3.

Therefore the first comparator lane reveals a **sampling/preprocessing sensitivity**, not merely an inter-tool difference. Deterministic resampling is information-matched between tools but is not semantically neutral for every stochastic process.

This prevents treating the first SOMATA run as a clean end-to-end comparison of the original 256 Hz qualification task.

## Nonoscillatory controls

SOMATA iOsc has no zero-oscillator candidate in this frozen lane.

Results:
- nonoscillatory AR(1): 1 oscillator in 1/3; 2 in 2/3;
- white noise: 2 oscillators in 3/3.

These rows remain `NOT_DIRECTLY_COMPARABLE_ZERO_OSCILLATOR_ABSENT_IN_IOSC`.

They do not show that SOMATA “failed” a zero-oscillator task because that task is absent from the model family. They do show why a second comparator lane with an explicit nonoscillatory alternative is necessary before making any model-family adequacy claim.

## Residual diagnostics

SOMATA's native residual-diagnostic bundle was successfully emitted for every run.

The output is retained as package-native evidence. No residual p-value threshold is promoted from this first run because:
- the comparator family differs from NSD;
- the diagnostic semantics are package-specific;
- the valid-single rows themselves can show small native residual-test p-values.

## P0-Q disposition

This first standard-toolkit lane earns:

1. SOMATA is mechanically executable and reproducible in the NSD environment.
2. Both approaches recover the gross single-versus-separated-two-mode structure on the frozen matched signal.
3. Close-mode and frequency-shift cases retain nontrivial disagreement.
4. iOsc alone cannot adjudicate zero-versus-oscillator behavior.
5. resampling to 120 Hz materially changes the NSD task for some stochastic controls.

It does **not** earn:
- an overall tool ranking;
- ADDS/EQUIVALENT/SUBTRACTS;
- a production admission threshold;
- real-EEG local chi.

## Next comparator gate

A second comparator version is scientifically justified, but it must be prospectively frozen.

Two issues must be separated:
1. remove the resampling-semantic confound by generating matched known truth natively at the comparator sampling rate;
2. include a standard-toolkit nonoscillatory alternative so A0-like refusal is actually comparable.

No further comparator result should be opened until that second-lane design is frozen.
