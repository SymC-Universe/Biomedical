## Objective

Determine why the completed C-interior Function Map contains a reproducible C1Q boundary-collapse branch. The diagnostic separates three live explanations without changing the estimator:

1. realized finite-sample likelihood geometry genuinely favors the pathological boundary branch over the population generating coordinates;
2. the current multi-start search misses a better truth-near local basin;
3. the truth-near and selected basins are both competitive enough that the region is practically weakly identified under the current parameterization/data duration.

This is a root-cause experiment on already-viewed synthetic known truths. It cannot validate C biologically, promote C1Q, or define a real-data admission threshold.

## Frozen source rows

The diagnostic uses **all rate-level rows** from Function Map cells

\[
\{0,5,7,8,9,11,12,15\},
\]

the eight cells identified in the postresult as containing the boundary-collapse family. This includes both collapsed and noncollapsed rows within those cells. The selection is cell-based rather than error-threshold-based so no new scientific cutoff is introduced after viewing outcomes.

With three frozen realization seeds and two sampling rates, this yields 48 source rows.

The source selected-fit raw parameters and selected-fit NLL are read directly from the immutable complete Function Map artifact. They are not regenerated by another global multistart fit.

## Exact diagnostic

For each source row:

1. regenerate the exact known-truth realization from the frozen cell coordinates, seed, duration, and sampling rule;
2. reconstruct the population generating coordinates in C1Q raw parameterization:
   - \(A\) from the truth latent fraction;
   - \(\rho=e^{-\alpha/f_s}\), where \(\alpha=2\pi f_n\chi\);
   - \(f_d=f_n\sqrt{1-\chi^2}\);
   - raw \(g=\operatorname{atanh}(g)\);
3. standardize the regenerated row exactly as C1Q does;
4. evaluate C1Q NLL at the generating raw coordinates;
5. evaluate NLL at the stored selected raw coordinates and verify agreement with the stored Function Map NLL to numerical tolerance;
6. run one L-BFGS-B local optimization from the generating raw coordinates using the same \([-8,8]^4\) parameter box and C1Q likelihood;
7. optionally re-polish the stored selected coordinates with one local optimization only as a numerical consistency check, not a new global search;
8. record all basin coordinates, NLLs, per-effective-sample NLL differences, transformed physical parameters, raw-bound distances, optimizer success, and parameter-space distances.

## Interpretation architecture

No empirical scientific threshold is defined.

**Search failure is directly demonstrated** if a truth-seeded local optimization obtains an NLL lower than the stored selected solution beyond the declared floating-point comparison tolerance. This is a computational inconsistency with the prior selected optimum, not a biological threshold.

**Likelihood-geometry pressure is supported** when the stored selected branch has lower realized NLL than the generating coordinates and truth-seeded optimization moves materially away from the generating point toward a lower-NLL basin. Parameter movement and NLL differences are reported continuously rather than thresholded.

**Practical weak identification remains live** when truth-near and selected solutions are both locally admissible and have similar realized likelihood despite large parameter separation. This experiment reports the continuous likelihood gap and parameter displacement; it does not freeze the word "similar" into an admission rule.

**Implementation/provenance failure** is declared if the exact regenerated selected-coordinate NLL does not reproduce the source artifact to the numerical tolerance, the frozen path cannot be regenerated, or the truth coordinates cannot be represented in the declared C1Q box.

## Numerical tolerance

The only frozen tolerance is a **mechanical reproducibility tolerance**, not a scientific threshold:

\[
|\mathrm{NLL}_{recomputed}-\mathrm{NLL}_{artifact}|
\le
10^{-6}\max(1,|\mathrm{NLL}_{artifact}|).
\]

Failure of this check blocks interpretation because source identity has not been reproduced.

## Claim ceiling

This P0-Q diagnostic may identify optimization failure, finite-sample likelihood geometry, or practical weak-identification structure for the current C1Q implementation. It does not:

- modify C1Q;
- choose a new optimizer;
- promote a new estimator;
- define an admission/refusal threshold;
- estimate biological prevalence;
- license real EEG;
- reinterpret the C family as biologically established.

## Reproducibility class

Exact design identity and source-artifact row identity are required. Floating-point NLL comparisons use the declared mechanical tolerance. Local optimization is expected to be numerically/decision-equivalent within the declared Python/NumPy/SciPy environment; cross-platform bitwise identity is not required.

## Stopping rule

Run the complete 48-row diagnostic unless a shared mechanical/provenance defect prevents valid interpretation. Scientific heterogeneity, unexpected basin behavior, or null separation is preserved and does not trigger plan retuning.

## Expected information gain

This is the cheapest discriminating test before any estimator redesign. It decides whether the next engineering question is global-search coverage, likelihood/parameterization geometry, or uncertainty/refusal characterization.
