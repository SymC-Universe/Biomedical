## Findings

1. **Strongest feature:** the plan explicitly tests whether practical identifiability and semantic admissibility are separable rather than assuming a compact profile licenses the model.
2. **Strongest assumption:** C1Q-RS profile geometry is worth carrying forward as a component of admission even though prior evidence shows fit quality alone cannot establish C membership.
3. **Most likely failure mode:** D\C, S\D, colored, or two-mode truths may produce compact profiles, making morphology appear non-discriminating if one expects a universal refusal signature.
4. **Hidden dependency:** all profile geometry is conditional on the C1Q likelihood family. A compact profile can only mean the imposed C likelihood is locally well determined, not that the likelihood is semantically correct.
5. **Competing explanation:** apparent class differences may be driven primarily by signal-to-noise, duration, and frequency content rather than semantic truth class.
6. **Coverage concern:** the six C cases span useful interior/transition roles, but the Limit cases are canonical exemplars, not a prevalence-weighted sample.
7. **Missing control:** the merged result should explicitly compare morphology within the C family before comparing C versus Limit truth, so weak-valid C behavior is not conflated with semantic failure.
8. **Refusal condition:** if regular nominal C cases do not show mechanically reproducible profile geometry across seeds/rates, the profile method must be re-opened before interpreting Limit cases.
9. **Material objection A1:** “profile-based refusal architecture” must not imply profile geometry itself is expected to refuse semantic mismatch. The plan should instead calibrate the **division of labor** between practical-identifiability and semantic gates.
10. **Material objection A2:** near-critical and g-boundary C cases must remain explicitly valid-C transition cases even if their profiles look pathological.
11. **Minor A3:** the high-frequency C case is an estimator-frequency-edge stress case, not a true alias-collapse case and should be named accordingly.

## Disposition recommendation

Proceed after revising the wording so the primary target is: profile likelihood qualifies **practical identifiability**, while the experiment asks which semantic failure classes remain invisible to profile morphology and therefore require independent family/order/closure gates.
