# Bio Chi C1Q-RS Untouched Qualification APQ Pass B v0.1

**Lens:** computation, independence, reproducibility, fairness  
**Isolation:** role-isolated same-cognition first pass

The strongest feature is exact code parity: legacy C1Q and C1Q-RS run on the same realized paths with the same primary/rescue budgets.

The most dangerous hidden dependency is accidental reuse of a development coordinate or seed. Exact frozen tables and explicit seed sets make that mechanically auditable.

A second risk is outcome leakage from a preflight. The preflight must remain mechanical; poor scientific recovery cannot modify coordinates, seeds, budgets, or outputs.

The strict containment invariant is necessary but not sufficient because it is partly guaranteed by construction. Scientific information comes from whether unseen rows actually expose useful recurrence-informed basin rescue and whether recovery behavior develops a new pathology.

**B1 MATERIAL:** preflight outcome leakage could contaminate the untouched design.  
**Disposition:** mechanical-only preflight stop rules frozen explicitly.

**B2 MATERIAL:** C1Q-RS extra compute may have runtime cost even if it provides little unseen utility.  
**Disposition:** record recurrence readiness/winner counts and runtime/start counts; lack of unseen rescue is a valid no-added-utility outcome.

**B3 MINOR:** three seeds remain descriptive, not an estimate of failure probability.  
**Disposition:** no prevalence/probability language.
