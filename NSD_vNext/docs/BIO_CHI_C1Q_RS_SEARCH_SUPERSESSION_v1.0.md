# Bio Chi C1Q-RS Qualification Search Supersession Record v1.0

**Status:** ACTIVE IMPLEMENTATION PREFERENCE  
**Date:** 27 September 2026  
**Governed by:** SymC General Operations Manual v1.0

C1Q-RS is the preferred **qualification search implementation** for future C-family work.

This preference is supported by:

- development Function/Limit qualification showing strict containment and repair of legacy basin failures;
- untouched qualification run `36371426674`, which passed strict non-worsening in 96/96 unseen rows and found lower-NLL basins across multiple unseen cells, seeds, and rates without a new reproducible recovery failure mechanism.

The supersession affects optimizer/start-search implementation only. The C1Q likelihood family, parameterization, parameter count, claim ceiling, and semantic admission requirements are unchanged.

Legacy C1Q remains preserved as a historical/regression comparator and must be used when reproducing artifacts frozen before this supersession.

C1Q-RS is **not** promoted to a production biological estimator and is **not** evidence of C-family membership in real data.
