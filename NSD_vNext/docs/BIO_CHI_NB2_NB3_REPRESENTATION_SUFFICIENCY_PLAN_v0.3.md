## Residual scientific target

The contribution is not a new theory of minimal realization, non-normality, DMD, controllability, or model reduction.

The target is a governed Stability Function/Limit benchmark:

> For a prospectively declared stability target and information contract, which representation sets are sufficient, which are insufficient, which are non-invariant, and which are not recoverable from the declared observations?

The result is a target-specific sufficiency/refusal map.

## Representation information sets

The candidate information sets include local modal damping/frequency coordinates, embedded eigenspectrum, non-normal/reactivity structure, finite-time propagator structure, explicit perturbation and observation operators, and full frozen state-space/operator structure.

These form a partial order by information content. They are not assumed to form one universal scientific ladder.

## Two-layer adjudication

### Layer E: exact information sufficiency

Uses generating truth only and asks whether a representation contains enough information to reproduce the frozen target observable under the frozen metric, perturbation, observation, and horizon.

Primary states:

- `EXACT_SUFFICIENT_MINIMAL`
- `EXACT_SUFFICIENT_NONMINIMAL`
- `EXACT_INSUFFICIENT`
- `REFUSED_NOT_INVARIANT`
- `NOT_APPLICABLE`

### Layer R: recoverability under observation

Uses only the frozen sampled/observed information contract and asks whether the required representation can be identified reproducibly.

Primary states:

- `RECOVERABLE`
- `REFUSED_NOT_IDENTIFIABLE`
- `NEED_MORE_INFO`
- `NOT_APPLICABLE`

Exact sufficiency cannot be promoted into empirical recoverability.

## Target observables

The separate targets remain asymptotic stability, embedded modal organization, peak transient amplification, transient peak timing/direction, perturbation-specific recovery trajectory, integrated recovery burden, observed recovery after C, and reorganization under explicit time variation.

No single target stands in for all others.

## Invariance and metric firewall

The execution packet must freeze a physically declared state metric when state-norm quantities are used, plus input and output norms where applicable. The metric must transform consistently under similarity changes.

If no physical metric exists for a cross-realization comparison, state-norm gain and eigenvector conditioning remain descriptive and cannot support cross-realization sufficiency claims.

Input-output response remains the preferred invariant control when B and C are scientifically part of the target.

## Function Map requirements

The exact packet must include ordinary success regions:

- decoupled or normal systems where low-order information is sufficient;
- normal coupled systems where eigenspectrum is sufficient for asymptotic/modal targets;
- strongly non-normal stable systems where non-normal or propagator information is genuinely necessary and sufficient for finite-time targets;
- input-output aligned systems where B/C reduce the effective target space;
- valid partially observed cases where the observable target remains recoverable despite latent complexity;
- stationary and explicitly time-varying Function cases where the correct representation is known.

## Limit Map requirements

Matched families must include:

- same local damping with different embedded spectra;
- same local damping and same eigenspectrum with different non-normal transient response;
- same A with different B;
- same A and B with different C;
- similarity-related realizations;
- time-varying truth versus stationary surrogate;
- unobservable latent modes;
- finite-duration and sampling challenges;
- correct local modal vector with insufficient system response information.

## Matched-pair identity rule

The execution packet must define exact equality or a predeclared numerical identity tolerance for every quantity claimed held fixed. No post-result visual matching is allowed.

## Recovery firewall

Primary recovery evidence consists of full response curves and continuous functionals over a frozen finite horizon. Thresholded return times are secondary diagnostics only and require prospectively frozen thresholds and sensitivity analysis.

## Time-variation firewall

A time-varying truth must be defined by a prospectively bound operator sequence or law. Its stationary surrogate must be generated by a predeclared procedure independent of the observed sufficiency result.

## Claim ceiling

The experiment can establish only a known-truth, target-specific representation-sufficiency and recoverability map under the frozen contracts. It cannot establish a universal representation hierarchy, a whole-brain chi, biological prevalence, disease meaning, real-EEG local chi, or discovery of established native methods.
