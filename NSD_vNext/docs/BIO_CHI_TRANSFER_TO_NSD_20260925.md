## 2. What transfers scientifically

Only architecture and earned methodological rules transfer.

### Scalar level

A biological/local scalar is optional.

A local scalar may be called `chi` in SymC bookkeeping only where a native model licenses an exact dynamical quantity. In NSD, native terminology leads:

`modal damping ratio zeta_i <-> local chi_i`

only where the equivalence is exact or operationally validated.

No scalar is manufactured from:
- descriptive PSD peak location;
- aperiodic exponent;
- covariance alone;
- session similarity;
- state ordering;
- spectral width whose broadening origin is unresolved.

No universal `chi = 1` neural boundary is assumed.

### Modal/vector level

The modal/vector layer may remain scientifically useful when no local scalar is licensed.

It may include:
- qualified poles/eigenmodes;
- mode shapes and participation;
- modal uncertainty/conditioning;
- spatial participation;
- mode-specific perturbation/state behavior;
- refusal states where modal identity is not stable.

Scalar refusal does not invalidate the modal layer.

### Conglomerate/system level

The broader Bio Chi question becomes, in native NSD terminology:

> How do local modal dynamics, modal/vector organization, coupling, topology, spatial participation, transient amplification, perturbation response, recovery/return, context, and history jointly determine embedded neural-system behavior?

This is not an arithmetic score and is not a new parameter named `Chi_NSD`.

Native system objects lead:
- system matrix / Jacobian;
- transition/evolution operator;
- eigenspectrum;
- spectral abscissa;
- non-normality/reactivity;
- maximum transient gain;
- pseudospectral/resolvent sensitivity;
- mode shapes/participation;
- spatial/coupling organization;
- recovery/return descriptors where ordered perturbation permits them.

## 6. New Bio Chi target in NSD

The investigation now asks three coequal questions.

### N-B1: licensed local scalar

Where a neural mode is genuinely licensed, what does its modal damping ratio/local chi explain about:
- persistence;
- perturbation response;
- return;
- state transition;
- spatial participation?

If no licensed scalar exists, N-B1 refuses without blocking N-B2/N-B3.

### N-B2: modal/vector architecture

Does qualified modal/vector organization retain information about neural state and perturbation behavior that scalar compression loses?

Primary concern:
- mode identity;
- multiplicity;
- participation;
- spatial structure;
- stationarity;
- conditioning;
- representation dependence.

### N-B3: embedded system architecture

Do coupling/topology/transient/recovery/system-level descriptors add information beyond local/modal structure under matched information and comparator budgets?

Required adversaries include:
- same local damping, different coupling;
- different local damping, similar embedded response;
- locally stable, globally unstable;
- topology change with preserved local spectra;
- non-normal systems with identical eigenspectra but different transient gain;
- temporal reorganization that whole-record modal order can hide.

## 7. Joint-meaning rule

The target is not to produce three numbers.

The target is to determine the relation:

`local licensed dynamics -> modal/vector organization -> embedded system behavior`

and the reverse conditioning:

`coupling / topology / context / history -> realized meaning of local modal dynamics`.

Valid outcomes include:
- local scalar sufficient for a narrow task;
- modal/vector layer adds beyond local scalar;
- system-level architecture adds beyond local/modal;
- no scalar licensed but modal/system structure remains reproducible;
- native neural methods equal or outperform the proposed architecture;
- no coherent shared architecture across the tested regime.
