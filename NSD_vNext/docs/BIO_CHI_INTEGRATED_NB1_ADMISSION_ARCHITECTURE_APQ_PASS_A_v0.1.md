# Bio Chi Integrated N-B1 Admission Architecture APQ Pass A v0.1

**Plan reviewed:** `BIO_CHI_INTEGRATED_NB1_ADMISSION_ARCHITECTURE_PLAN_v0.2.md`  
**Lens:** scientific meaning, semantic refusal, decision grammar, Function/Limit balance  
**Independence:** role-isolated review from one cognition; not an independent reviewer.

## Findings

1. The strongest feature is the noncompensatory architecture: no favorable gate can cancel failure of another required gate.
2. The largest semantic risk is collapsing every failure into one generic `REFUSED` state. Family mismatch, estimator-route failure, missing information, and data-contract failure do not mean the same thing.
3. Every channel therefore needs its own prospective state grammar: `PASS`, `REFUSE`, `NEED_MORE_INFO`, or `NOT_APPLICABLE`.
4. Applicability itself must be frozen. Observation/reference sensitivity, paired-rate checks, and time-variation checks are conditional channels and cannot be invoked post hoc only when a result is inconvenient.
5. Local-chi refusal must preserve any still-licensed modal/vector Chi and broader system information rather than turning scalar refusal into whole-record failure.
6. `QUALIFICATION_ELIGIBLE` must mean eligible only for a later untouched known-truth qualification packet, never real-EEG admission.
7. The framework needs an explicit `FRAMEWORK_NOT_OPERATIONAL` outcome if the conjunction cannot retain ordinary valid Function cases without circular tolerance tuning.
8. The untouched packet must distinguish semantic-invalid truths from semantically valid truths whose current estimator/search route fails.

## Material objections

- **A1 MATERIAL:** generic `REFUSED` is semantically overloaded.
- **A2 MATERIAL:** conditional channel applicability is under-specified.
- **A3 MATERIAL:** semantic refusal and estimator-route refusal are not yet formally separated.
- **A4 MATERIAL:** `FRAMEWORK_NOT_OPERATIONAL` must remain available as a global qualification outcome.
- **A5 MATERIAL:** scalar refusal must explicitly preserve broader licensed representations.

## Disposition recommendation

Proceed only after revising the plan so refusal semantics, applicability, and preservation rules are explicit before construction of any untouched integrated packet.
