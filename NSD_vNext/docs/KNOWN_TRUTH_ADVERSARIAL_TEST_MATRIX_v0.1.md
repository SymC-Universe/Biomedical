# NSD Known-Truth and Adversarial Test Matrix v0.1

Date: 14 September 2026
Status: PRE-COMPUTE QUALIFICATION DESIGN
Purpose: define what the Structural Engine must recover, refuse, or remain uncertain about before clinical labels are allowed to matter.

## 1. Principle

The historical NSD work showed that an attractive state-space picture can be constructed without proving that the plotted coordinates are recoverable from data. The rebuild therefore places **known-truth and adversarial recovery before clinical separation**.

The first Engine question is not “does this separate diagnoses?” It is:

> “When the truth is known, does the Engine recover the right structure, and when the model is wrong, does it refuse rather than invent stability?”

## 2. Synthetic signal families

### KT-01 — Pure second-order stochastic oscillator

Generator:
- one damped harmonic oscillator;
- known natural frequency;
- known damping ratio / decay rate;
- white-noise drive.

Sweep:
- underdamped through near-critical regimes where oscillatory identification remains meaningful;
- multiple SNRs;
- recording durations;
- sampling rates.

Pass target:
- recover frequency and damping within prespecified bias/coverage tolerance;
- uncertainty widens as information degrades;
- refusal occurs when identification becomes inadequate.

### KT-02 — Sum of two separated oscillatory modes

Purpose:
- test mode-order recovery;
- test whether one broad peak is incorrectly substituted for two modes.

Sweep:
- frequency separation;
- amplitude imbalance;
- damping imbalance;
- phase relation;
- SNR.

Pass target:
- two modes when resolvable;
- uncertainty/model ambiguity when marginal;
- no fabricated single “whole signal chi.”

### KT-03 — Two unresolved neighboring modes

Purpose:
- create apparent broadening that is not increased damping.

Pass target:
- Engine does not interpret merged width as a unique damping rate without model support;
- expected refusal: `REF_BROADENING_UNRESOLVED` or model ambiguity.

### KT-04 — Frequency-drifting oscillator

Generator:
- stable damping;
- center frequency slowly or abruptly changes over time.

Purpose:
- test heterogeneous/nonstationary broadening.

Pass target:
- static spectral width must not be read automatically as stronger damping;
- time-resolved diagnostics should expose drift where resolution permits.

### KT-05 — Burst oscillator

Generator:
- intermittent finite-duration oscillatory bursts;
- fixed within-burst frequency;
- variable burst durations.

Purpose:
- distinguish burst statistics from continuous exponential decay.

Pass target:
- no unconditional width-to-damping conversion;
- burst duration and spectral width reported separately.

### KT-06 — Aperiodic-only signal

Generator:
- 1/f-like background with no periodic peak.

Pass target:
- correct zero-peak state;
- no imputed mode;
- no dynamical chi;
- `REF_NO_PEAK` when a mode-specific scalar is requested.

### KT-07 — Aperiodic background plus Gaussian bump with no second-order generator

Purpose:
- test whether a descriptive peak is falsely mechanized.

Pass target:
- peak features may be measured;
- dynamical chi withheld unless an explicit model wins qualification.

### KT-08 — Nonlinear/limit-cycle oscillator

Purpose:
- test whether the linear damped-oscillator model is incorrectly forced onto dynamics generated by a qualitatively different mechanism.

Pass target:
- diagnostics indicate model mismatch or poor residual structure;
- linear chi is not promoted simply because a peak exists.

### KT-09 — Colored-noise driven oscillator

Purpose:
- break the white-noise input assumption.

Pass target:
- assess parameter bias under realistic colored drive;
- define the regime in which recovery remains acceptable versus refused.

### KT-10 — Coupled oscillator network

Generator:
- local modes with controllable coupling;
- known mode shapes/eigenmodes.

Pass target:
- evaluate whether channel-wise fitting confuses network modes with local modes;
- test recovery of modal participation and spatial organization.

## 3. Spectral-model adversaries

### ADV-01 — Window-length broadening

Hold generator fixed, vary data duration and Welch window configuration.

Failure signature:
- inferred damping moves primarily with analysis settings.

Required action:
- configuration robustness bounds or refusal.

### ADV-02 — Frequency-resolution limit

Construct modes narrower than available spectral resolution.

Required action:
- uncertainty/refusal, not artificially precise width.

### ADV-03 — Line-noise proximity

Place a legitimate mode near 50/60 Hz and harmonics.

Required action:
- quantify notch/filter impact;
- no silent mode deformation.

### ADV-04 — Aperiodic-fit misspecification

Compare fixed versus knee backgrounds where the true generator contains a knee.

Required action:
- expose resulting periodic-parameter bias;
- choose/freeze model by label-blind fit criteria.

### ADV-05 — Peak-shape mismatch

Generate Lorentzian peaks and fit Gaussian peaks, then reverse.

Purpose:
- quantify how center/width/power change under model mismatch.

Required action:
- no width-to-damping conversion from a mismatched descriptive model.

## 4. Spatial and acquisition adversaries

### ADV-06 — Volume conduction / source mixing

Mix known source modes across sensor channels.

Pass target:
- quantify when apparent regional similarity is caused by mixing;
- avoid interpreting sensor-level homogeneity as biological synchronization without caveat.

### ADV-07 — Reference transformation

Apply common-average, linked-mastoid, and other appropriate references to the same synthetic/real benchmark.

Pass target:
- characterize which features are reference-sensitive.

### ADV-08 — Channel dropout/interpolation

Remove and interpolate spatially structured channels.

Pass target:
- quantify distortion of spatial/conglomerate features;
- define missingness thresholds.

### ADV-09 — Site/device transfer

Where public data permit, compare acquisition systems or simulate response/filter differences.

Pass target:
- Atlas site effects remain visible;
- clinical effect is not accepted if dominated by hardware/site.

## 5. Hierarchy and statistics adversaries

### ADV-10 — Session duplication

Duplicate sessions/epochs from the same subject while keeping subject count fixed.

Pass target:
- inferential uncertainty must not improve as though new independent subjects were added.

### ADV-11 — Label leakage

Inject diagnosis information into preprocessing or threshold selection in a controlled test.

Pass target:
- audit tooling detects prohibited configuration dependence or the protocol catches it before P1.

### ADV-12 — Class imbalance

Vary diagnosis prevalence without changing feature distributions.

Pass target:
- reported metrics remain prevalence-aware;
- balanced accuracy/AUROC/etc are interpreted correctly;
- no accuracy inflation.

### ADV-13 — Healthy-baseline retuning

Attempt to recompute the reference baseline separately for each disorder comparison.

Pass target:
- version controls reject or explicitly flag the baseline change.

## 6. Open-channel adversaries

### ADV-14 — No-peak subjects

Purpose:
- ensure that absence is retained rather than numerically imputed.

### ADV-15 — Catastrophic poor fit

Purpose:
- ensure residual/model error flows to a refusal state.

### ADV-16 — Conflicting estimators

Construct data where a spectral-width method and a time-domain/state-space method disagree materially.

Pass target:
- `REF_MODEL_DISAGREEMENT` or uncertainty escalation;
- never choose the estimator that best separates labels after the fact.

## 7. Minimum qualification metrics

The implementation must report, as applicable:
- parameter bias;
- RMSE;
- interval coverage;
- false-mode rate;
- missed-mode rate;
- correct-refusal rate;
- false-admission rate;
- model-order accuracy;
- scalar-admission accuracy;
- robustness slope versus nuisance parameter;
- calibration of uncertainty;
- runtime/resource use.

## 8. Known-truth promotion rule

A dynamical estimator may advance toward P0-Q only after:
1. recovery succeeds over a declared intended operating region;
2. failure behavior is mapped outside that region;
3. refusal works when assumptions fail;
4. nuisance sensitivity is bounded;
5. the operating region is frozen before clinical evaluation.

## 9. Clinical-data firewall

No disorder label may be used to set the pass thresholds in this matrix.

After known-truth qualification, real healthy neurophysiology is used to test label-blind adequacy and reproducibility. Only then does diagnosis enter as an overlay.

This ordering is deliberately designed to prevent a repeat of the historical “show becomes evidence” failure mode.
